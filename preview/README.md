## 一、它验证什么

用程序化几何体搭出 L1 核心 8 件样板家具，验证规范的四个风格项：

- 造型：低多边形 + 大圆角，"矮胖软萌"比例
- 配色：规范 3.3 色板（奶油白 / 原木 / 鼠尾草绿 / 芥末黄 / 陶土粉）
- 光照：半球环境光 + 方向光软阴影 + 接触阴影
- 视角：正交相机，方位 45°、俯角 30°

## 二、运行

无需 npm 安装（Three.js 已本地化到 `vendor/`，完全离线）。

```bash
cd /Users/Admin1/Documents/kywork/3d/preview
python3 -m http.server 8123 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8123/index.html`。

> 必须通过 HTTP 访问，不能双击 HTML 直接打开——ES module 与 importmap 需要 HTTP 协议。

## 三、操作

| 操作 | 方式 |
|---|---|
| 移动家具 | 在家具上按住拖动，按 0.1 米网格吸附，自动钳制在房间边界内 |
| 旋转视角 | 在空白处按住拖动（俯角限制在 0.18～1.15 弧度） |
| 缩放视角 | 鼠标滚轮 |
| 选中家具 | 点击家具或左侧目录卡片，显示名称与尺寸 |
| 关闭吸附 | 左下角「吸附：开/关」按钮 |
| 复位 | 「重置视角」按钮，恢复相机与视角 |

## 四、文件结构

| 文件 | 职责 |
|---|---|
| `index.html` | 页面骨架、importmap、目录与操作面板 |
| `src/style.css` | 界面样式（与规范色板一致的暖色调） |
| `src/materials.js` | 共享哑光材质库（规范 3.3 / 3.4） |
| `src/furniture.js` | 8 件程序化家具与目录元数据（规范 3.2 / §4） |
| `src/scene.js` | 房间、相机、光照、接触阴影（规范 3.4 / 3.5） |
| `src/main.js` | 初始布置、拾取高亮、拖拽、吸附、视角控制 |
| `vendor/three.module.js` | Three.js r169（本地化，MIT） |
| `vendor/RoundedBoxGeometry.js` | 圆角盒几何扩展（本地化） |
