## 一、背景与目标

### 1.1 项目定位

本项目的核心是**记录物品收纳**。家具在三维场景中不是主角，而是物品的容器与承载面——用户关心的是"东西放在哪、怎么收、拿没拿走"，而不是家具本身的展示效果。因此本规范的取舍原则是：**收纳表达优先于视觉丰富度**。

### 1.2 视觉目标

视觉参考为「等距娃娃屋场景 + 治愈系低多边形家具 + 品类目录拖拽摆放」这一形态。概括起来是四个特征：

- 视角：斜俯视的等距/弱透视视角，房间像打开的娃娃屋，前墙隐藏。
- 造型：低多边形 + 大圆角，比例偏"矮胖软萌"，不做写实细节。
- 配色：低饱和、高明度、整体低对比，暖调原木与奶油色为主。
- 光照：柔和环境光 + 软阴影，无硬高光与强反射。

### 1.3 目标边界

| 要做 | 不做 |
|---|---|
| 固化风格标准，使批量家具风格一致 | 追求照片级渲染或 CAD/BIM 精度 |
| 用最小家具集覆盖日常收纳场景 | 铺开全品类家具库 |
| 用程序化几何体快速验证风格 | 在验证阶段投入正式美术资产 |
| 与既有小程序三维场景口径衔接 | 改变既有的物品—位置业务逻辑 |

## 二、技术路线

整体分五个阶段，前两阶段属于美术管线，后三阶段属于工程管线：

**风格定义 → 资产建模 → 渲染接入 → 摆放交互 → 优化交付**

| 阶段 | 核心工作 | 产出 | 退出条件 |
|---|---|---|---|
| 1 风格定义 | 冻结 Style Guide：造型、尺寸、配色、材质、光照、视角 | 本规范文档 | 风格评审通过 |
| 2 资产建模 | Blender 按规范建模，统一锚点/碰撞/元数据，导出 GLB | 家具资产库 | 样板件验证通过 |
| 3 渲染接入 | 场景基底、相机、光照、材质库接入 | 可运行的预览场景 | 场景可稳定渲染 |
| 4 摆放交互 | 目录、拾取拖拽、网格吸附、碰撞校验、撤销重做 | 可交互的预览 | 摆放流程闭环 |
| 5 优化交付 | 共享材质、实例化、加载降级、机型适配 | 优化后的预览与资产 | 帧率与加载达标 |

风格定义是所有后续工作的前提。规范未冻结就批量建模，返工成本极高。

## 三、风格规范（Style Guide v0.1）

### 3.1 造型与比例

- 低多边形 + 大圆角倒角，形体偏"矮胖软萌"；禁止锐边、复杂雕花、真实人体工学曲线。
- 风格靠**轮廓与圆角**表达，不靠细节堆料。软包件用 2～3 个圆角体块拼出坐垫与靠背即可。
- 单件家具点缀色不超过 2 种，避免视觉碎片化。

### 3.2 尺寸基准

以下为建模建议基准尺寸（单位：米，宽 × 深 × 高），用于统一比例感；非测量承诺，评审后可调整。坐标系沿用项目既有约定：Y-up，单位米。

| 家具 | 建议尺寸（宽×深×高 m） | 说明 |
|---|---|---|
| 沙发（双人） | 2.0 × 0.9 × 0.8 | 客厅主件，兼临时置物 |
| 床 | 1.5 × 2.0 × 0.5 | 含床下收纳语义 |
| 椅子 | 0.8 × 0.8 × 0.8 | 通用坐具，可搭衣物 |
| 桌（餐桌/书桌通用） | 1.4 × 0.8 × 0.75 | 台面置物主平面 |
| 茶几 | 1.0 × 0.6 × 0.4 | 客厅置物平面 |
| 衣柜 | 1.2 × 0.6 × 2.0 | 封闭收纳主件 |
| 斗柜/抽屉柜 | 1.0 × 0.45 × 0.9 | 小件分类收纳 |
| 书柜/置物架 | 0.9 × 0.35 × 1.8 | 开放收纳，常取物品 |
| 床头柜（L2） | 0.5 × 0.4 × 0.5 | 按需纳入 |
| 鞋柜（L2） | 0.9 × 0.35 × 1.0 | 按需纳入 |
| 橱柜（L2） | 1.2 × 0.6 × 0.85 | 按需纳入 |

### 3.3 配色板

以下为参考图风格的一套视觉建议值，评审后冻结。低饱和、高明度、整体低对比。

| 用途 | 色值 |
|---|---|
| 墙面 / 地面 | `#F5EFE3` / `#D9B98C` |
| 主角色（木 / 布） | `#C9A87C`、`#E8DED0` |
| 点缀色 | 鼠尾草绿 `#9CB49A`、芥末黄 `#E3C46B`、陶土粉 `#D8A79C` |
| 深色收口 | `#5A5148` |

### 3.4 材质与光照

- 哑光 PBR：粗糙度偏高、金属度近 0；仅黄铜件、镜面等小面积允许例外。
- 一盏方向光产生柔和阴影，配半球环境光填充；启用接触阴影，避免物体"漂浮感"。
- 禁用强高光、强反射、硬边阴影。

### 3.5 视角与场景

- 正交相机或弱透视相机，方位角约 45°、俯角约 30°。
- 房间由地板 + 三面墙构成，前墙隐藏；窗光作为场景氛围来源。
- 色调映射 Neutral 或 ACES，曝光保守，开启抗锯齿。

## 四、家具品类体系（已确认精简版）

### 4.1 筛选原则

家具种类收敛到"日常收纳必要"三条标准：

a) 能装东西或放东西——优先收纳容器与置物平面。
b) 日常高频——几乎每个家庭每天都会用到。
c) 场景通用——不限定特殊空间或特定人群。

### 4.2 L1 核心必备（8 件）

| 分类维度 | 家具 | 收纳用途 |
|---|---|---|
| 坐卧承载 | 沙发 | 客厅临时放置（衣物、遥控器、包） |
| 坐卧承载 | 床 | 睡眠，兼床下收纳 |
| 坐卧承载 | 椅子 | 通用坐具，可搭衣物 |
| 台面置物 | 桌 | 餐桌/书桌通用，台面放置物品 |
| 台面置物 | 茶几 | 客厅置物平面 |
| 封闭收纳 | 衣柜 | 衣物、被褥 |
| 封闭收纳 | 斗柜/抽屉柜 | 杂物、小件分类 |
| 开放收纳 | 书柜/置物架 | 书籍、展示与常取物品 |

### 4.3 L2 按需补充（3 件）

默认不进入首版。当实际记录中出现"找不到放哪"的物品时再补。

| 家具 | 纳入条件 |
|---|---|
| 床头柜 | 卧室物品记录是重点时 |
| 鞋柜 | 入户收纳需要记录时 |
| 橱柜 | 厨房锅碗瓢盆是记录重点时 |

### 4.4 剔除清单

| 剔除项 | 理由 |
|---|---|
| 挂画、花瓶、镜子、摆件、绿植 | 不承载物品，纯装饰 |
| 地毯、窗帘、抱枕、床品、桌布 | 属背景织物，不是收纳对象 |
| 吊灯、台灯、壁灯 | 属照明，不参与物品记录 |
| 梳妆台、吧台、屏风、躺椅、飘窗垫 | 低频或非收纳功能 |
| 宠物、儿童、户外家具 | 特定人群/场景，首版不服务 |
| 主题套装 | 限定内容，与日常记录无关 |

### 4.5 分类维度

一级分类从通用方案的 11 个压缩到 4 个，每个维度对应一种摆放与绑定规则，交互实现随之简化：

1. 坐卧承载
2. 台面置物
3. 封闭收纳
4. 开放收纳

这 8 件同时作为预览验证的样板件，不再另做一批资产。

### 4.6 与既有项目基线的衔接（已确认：以本版为准）

既有小程序 `utils/constants.js` 中已有 `FURNITURE_LIB`（15 种）与三套 `ROOM_TEMPLATES`，视觉基线为方案 A「原木日常」（暖米白 `#FAF6EE` + 原木棕 `#9C6B3F` + 陶红 `#BE5F44`）。**2026-11-22 用户确认：本规范为后续执行的唯一基准**，既有基线中的冲突项以本版收敛，不再并行保留两套口径。

| 差异项 | 既有基线 | 本版（执行基准） | 落地口径 |
|---|---|---|---|
| 家具种类 | 15 种（含台灯、窗帘、躺椅、电视柜等） | L1 8 件 + L2 3 件 | 按本版收敛既有库；替换后须复核三套模板与已存家具的 category 引用 |
| 视觉色板 | 方案 A 三色 token | 本规范 3.3 色板 | 以本版色板为准；方案 A token 不再作为视觉基准 |
| 渲染载体 | 自建轻量 WebGL 渲染器 | 预览方案用 Three.js | 预览为独立验证载体，不替代小程序运行时；运行时是否切换另行决策 |
| 绑定语义 | 模型与逻辑节点解耦（BR-009） | 沿用 | 换外观模型不得破坏节点与物品关联 |

> 说明：本决策只确定"以哪套为准"，不改变本次交付范围。既有小程序代码、模板与视觉稿的同步修改属于后续执行任务，不在本版文档内实施。

## 五、资产交付规范

| 项 | 要求 |
|---|---|
| 面数 | 单件数百至数千三角面，建议上限按实机帧率回调 |
| 贴图 | 512～1024，共享图集，避免逐件独立大图 |
| 材质 | 全场共享材质，数量控制在十余种以内 |
| 锚点 | 每件带地面锚点；桌面/台面类带层级锚点，用于附着子物体 |
| 碰撞 | 提供 2D 占地框，不做复杂网格碰撞 |
| 导出 | `.glb` 单文件，必要时 Draco 压缩 |
| 命名 | 品类_名称_版本 |
| 元数据 | 一级品类、二级品类、适用空间标签、摆放类型、锚点类型、占地尺寸、风格标签 |

摆放属性按六类标注，直接决定交互规则：

| 类型 | 锚点与交互含义 |
|---|---|
| 落地件 | 地面锚点 + 2D 占地框，参与碰撞 |
| 桌面件 | 台面锚点，作为子物体附着，不占地面 |
| 壁挂件 | 墙面锚点，带朝向约束，仅贴墙移动 |
| 吊顶件 | 天花板锚点，通常固定位置 |
| 铺装件 | 地毯/地垫类，无高度碰撞（本版已剔除，规则保留备用） |
| 组合件 | 模块化家具，需组合与拆分规则（本版暂不涉及） |

## 六、预览验证方案

### 6.1 验证思路

阶段 0 **不依赖正式 GLB 资产**。用程序化几何体（圆角盒、圆柱、球体的组合）搭出 8 件样板家具，先验证配色、圆角、光照与视角——在没有美术投入的情况下最快判断"像不像"。风格确认后再进入 Blender 正式建模。

### 6.2 技术栈

| 项 | 选择 | 说明 |
|---|---|---|
| 渲染 | Three.js | 独立验证载体，迭代快、部署轻 |
| 构建 | Vite | 本地起服务，便于截图对比 |
| 相机 | 正交相机 | 方位约 45°、俯角约 30° |
| 光照 | 半球光 + 方向光软阴影 + 接触阴影 | 对应规范 3.4 |
| 材质 | 共享哑光材质库 | 对应规范 3.3 色板 |

### 6.3 场景与最小交互

- 场景：房间地板 + 三面墙（前墙隐藏）+ 窗光，8 件样板按 3.2 基准尺寸摆位。
- 最小交互：轨道旋转（限制角度）、缩放、拾取高亮、地面拖拽、网格吸附。
- 撤销重做：可后置，风格验证阶段非必需。

### 6.4 退出条件

1. 人眼对比参考图，风格评审通过（造型、配色、光照、视角四项均认可）。
2. 目标机型帧率达标，加载无卡顿。
3. 不通过则回到规范调整色板、圆角或光照，重新渲染对比，直至通过。

## 八、风险与约束

1. **风格一致性风险**：必须先冻结 Style Guide 并完成样板件，再批量建模。批量后再统一风格的返工代价远高于前期投入。
2. **规模风险**：家具品类多，优先模块组合复用（通用骨架 + 换材质/配件），而非全量单件建模。
3. **基线切换风险**：口径已确认以本版为准，但既有小程序代码、模板与视觉稿仍是旧基线。执行切换时须同步复核，避免出现两套视觉、两套家具库并行。
4. **参考图使用边界**：参考图仅用于风格取向，不照搬其中具体模型、图标与界面元素。
