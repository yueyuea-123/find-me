## 1. 页面 01：首页

### 页面目标
作为入口页，让用户一眼看到"家"的概览（户型、房间数、面积、空间列表），并提供四个高频操作入口。

### 页面结构（高保真元素）
- 顶部：标题"我的家"，右上角小程序胶囊。
- 空间概览卡：空间名（温馨的家）、户型与面积（3室2厅 · 120㎡）、户型俯视图。
- 四宫格入口：管理空间 / 添加物品 / 库存管理 / 更多。
- "我的空间"区块：区块标题 + "全部 >"，空间卡片（缩略图 + 名称 + 物品数量 + 进入箭头）。
- 底部 TabBar：空间 / 物品 / 库存 / 我的。

### 核心交互

| 按钮/元素 | 触发 | 结果 |
|---|---|---|
| 管理空间 | 点击 | 进入空间列表页（pages/space/space），可新增、编辑、归档、切换空间 |
| 添加物品 | 点击 | 进入物品建档页（pages/item-edit/item-edit）；未选位置时允许"位置未知"，进入后在移动页确认 |
| 库存管理 | 点击 | 切换到库存 Tab（pages/inventory/inventory） |
| 更多 | 点击 | 展开更多入口。菜单项限于已实现能力（备份/隐私/管理等）；未冻结功能不纳入 |
| 空间卡片 | 点击 | 进入该空间的房间/三维入口（pages/room/room），携带当前空间 ID |
| "全部 >" | 点击 | 进入空间列表页查看全部空间 |
| 底部 TabBar | 点击 | 切换对应一级 Tab，当前 Tab 高亮 |

### 操作结果 / 异常状态
- 概览统计（房间数、物品数）异步加载时显示骨架/占位，加载完成后回填。
- 无空间时：空间卡与空间列表显示空态，引导"创建空间"（来自管理空间入口）。
- 从其他页返回首页：刷新概览统计，保证物品数、库存提醒数一致。
- Tab 切换不重新加载整页数据，保持各 Tab 内部状态。

## 3. 页面 05：添加物品（物品建档 / 编辑）

### 页面目标
让用户为一件物品建立或更新档案：填写名称、分类、数量、存放位置与备注，并可拍摄/选择物品图片。新建与编辑共用本页（编辑时字段回填）。

### 页面结构（高保真元素）
- 顶部导航：返回 / 标题（添加物品）/ 更多。
- 物品图片区：物品大图（马克杯），可更换/拍摄。
- 字段：名称（马克杯）、分类（杯具）、数量（1）、存放位置（客厅 · 电视柜）。
- 备注（可选）多行输入。
- 底部固定："保存"主按钮。

### 核心交互

| 按钮/元素 | 触发 | 结果 |
|---|---|---|
| 物品图片 | 点击 | 调用 wx.chooseMedia 拍摄/从相册选择；选择后更新预览图。取消则不变更 |
| 名称 | 点击输入 | 必填；失焦或保存时校验非空 |
| 分类 | 点击 | 打开分类选择器；支持主分类与自定义标签（项目实现 P1-5，见业务规则）；选择后回填 |
| 数量 | 点击 | 数字输入/步进；正整数，最小值 1 |
| 存放位置 | 点击 | 打开位置选择器（空间 → 房间 → 家具 → 收纳位置层级）；选择后回填完整路径；允许"位置未知" |
| 备注 | 点击输入 | 可选，多行文本 |
| 保存 | 点击 | 校验通过后写入物品档案并返回；保存失败保留全部输入，不清空 |
| 返回 | 点击 | 若已有未保存修改，二次确认"放弃修改/继续编辑" |

### 字段与校验

| 字段 | 必填 | 校验 |
|---|---|---|
| 名称 | 是 | 非空，长度上限按业务规则 |
| 分类 | 否 | 从预置分类/自定义标签选择；标签规则见业务规则（去空白/去重/长度与数量上限） |
| 数量 | 是 | 正整数，最小值 1 |
| 存放位置 | 否 | 选择后写入 currentNodeId 与 spaceId；不选则记"位置未知"，后续在移动页首次确认 |
| 备注 | 否 | 文本 |

### 操作结果 / 异常状态
- 保存成功：新建返回来源页并刷新列表；编辑返回详情页展示更新后字段。
- 保存中：按钮进入 loading，禁用重复提交。
- 校验失败：错误就地展示在对应字段下，不用 toast 代替。
- 图片缺失/加载失败：显示统一占位图，不影响其他字段编辑与保存。
- 连续添加（项目实现）：保存后可继续新增下一件，表单清空、图片与标签重置。
- 来源预选：从三维家具/收纳位置进入建档时，存放位置按来源自动预选（见交互规范 V1.1 §5 与业务规则）。

## 4. 页面 06：我的物品

### 页面目标
让用户快速查找并浏览全部物品，按分类筛选，并进入物品详情。

### 页面结构（高保真元素）
- 顶部导航：返回 / 标题"我的物品" / 更多。
- 搜索框：占位"搜索物品…"。
- 分类筛选 Chip：全部 / 家居 / 数码 / 书籍 / 其他（当前选中高亮）。
- 物品列表：双列卡片，每卡含缩略图、名称、数量（如 x1、x3）。
- 底部 TabBar：空间 / 物品 / 库存 / 我的。

### 核心交互

| 按钮/元素 | 触发 | 结果 |
|---|---|---|
| 搜索框 | 输入关键字 | 实时过滤列表。匹配范围：名称、分类、备注、存放位置路径各层级名、自定义标签（项目实现 P0-1/P1-5） |
| 分类 Chip | 点击 | 切换分类筛选，仅显示该分类物品；"全部"取消筛选。选中态高亮 |
| 物品卡片 | 点击 | 进入物品详情（pages/item-detail/item-detail），携带物品 ID |
| 底部 TabBar | 点击 | 切换一级 Tab |

### 操作结果 / 异常状态
- 空列表（无任何物品）：显示空态 + 引导"添加物品"。
- 搜索无结果：显示"未找到相关物品"，保留搜索词与筛选条件，可清空重搜。
- 列表加载中：骨架卡片占位。
- 数据变更后返回本页：刷新列表，数量与筛选条件保持一致。

## 5. 页面 07：物品详情

### 页面目标
展示单件物品的完整信息与位置历史，提供收藏、编辑、删除入口。

### 页面结构（高保真元素）
- 顶部导航：返回 / 标题"物品详情" / 更多。
- 物品大图。
- 标题行：名称（马克杯）+ 分类标签（家居）+ 收藏星标。
- 信息行：数量（1件）、存放位置（客厅 · 电视柜）、添加时间（2026-11-23）、备注。
- 位置历史卡：时间线（2026-11-23 添加到 客厅 · 电视柜）。
- 底部操作：编辑（次按钮）/ 删除（危险红按钮）。

### 核心交互

| 按钮/元素 | 触发 | 结果 |
|---|---|---|
| 收藏星标 | 点击 | 切换收藏态：空心→实心 / 实心→空心；状态本地持久化 |
| 编辑 | 点击 | 进入物品编辑（复用 05 页），字段回填，携带物品 ID 与当前存放位置 |
| 删除 | 点击 | 弹出二次确认；确认后删除物品并清除相关绑定，返回列表页；取消则不变更 |
| 存放位置行 | 点击（如实现） | 进入移动页（pages/move/move）调整位置 |
| 位置历史卡 | 查看 | 展示该物品历次位置变更记录（来自 movements），全量可追溯 |

### 操作结果 / 异常状态
- 删除确认弹窗：明确删除后果，危险操作用低饱和红色（UI 规范）。
- 删除成功后返回列表，来源页刷新。
- 借出/外出态（项目实现 P1-4）：物品离开时常驻位置单独展示，与当前位置区分；归还后可自动回填。
- 位置历史多条时按时间倒序展示；无历史时显示初始建档记录。
- 物品已被删除/数据异常：显示友好提示并返回列表，不出现空白页。

## 6. 页面 08：库存管理

### 页面目标
让用户在统一入口查看物品余量、识别低库存并触发补货相关操作。库存提醒不改变物品与收纳位置的归属关系（交互规范 V1.1 §1）。

### 页面结构（高保真元素）
- 顶部导航：返回 / 标题"库存管理" / 更多。
- 筛选 Chip：全部 / 易耗品 / 长期用品（当前选中高亮）。
- 库存卡片列表：每卡含缩略图、名称、余量（剩余 3 包 / 8 节 / 1 瓶）、提醒状态（"低于 5 提醒"橙字 / "充足"绿字）、余量进度条（低=红、足=绿）。
- 底部固定："添加库存物品"主按钮。
- 底部 TabBar：空间 / 物品 / 库存 / 我的。

### 核心交互

| 按钮/元素 | 触发 | 结果 |
|---|---|---|
| 筛选 Chip | 点击 | 按全部/易耗品/长期用品切换列表；选中态高亮 |
| 库存卡片 | 点击 | 进入库存详情（pages/inventory-detail/inventory-detail），查看交易记录并执行入库/消耗/调整 |
| 添加库存物品 | 点击 | 进入库存详情/建档，为物品建立库存项（余量、单位、阈值） |
| 底部 TabBar | 点击 | 切换一级 Tab |

### 操作结果 / 异常状态
- 余量进度条颜色：低于阈值=红色并提示"低于 X 提醒"，充足=绿色"充足"；阈值来自库存项配置。
- 入库/消耗/调整后返回：余量与进度条同步刷新，交易记录追加一条。
- 消耗导致余额为 0：按业务规则提示；结束管理物品前须先将结存清零。
- 空库存：显示空态 + "添加库存物品"入口。
- 库存项对应的物品被删除：显示提示并引导清理，不显示孤立数据。

## 7. 跨页跳转与数据一致性（汇总）

| 起点 | 操作 | 终点 | 必须保持的数据 |
|---|---|---|---|
| 首页 | 点击空间卡片 | 房间/三维入口 | 当前空间 ID |
| 首页 | 添加物品 | 05 添加物品 | 来源缺省位置为空（位置未知） |
| 三维/家具 | 添加物品 | 05 添加物品 | 当前家具 ID、收纳位置 ID |
| 05 添加物品 | 保存成功 | 来源页（详情/列表/三维） | 物品 ID、存放位置 |
| 06 我的物品 | 点击物品卡 | 07 物品详情 | 物品 ID |
| 07 物品详情 | 编辑 | 05（编辑态） | 物品 ID、当前存放位置 |
| 07 物品详情 | 删除确认 | 06 我的物品 | 列表刷新 |
| 08 库存管理 | 点击卡片 | 库存详情 | 库存项 ID、物品 ID |
| 任意页 | Tab 切换 | 对应一级 Tab | 各 Tab 内部状态 |

> 两处口径提示：①"物品当前存放位置"在数据层为 currentNodeId（收纳位置），与"常驻位置" homeNodeId（项目实现）区分，借出/外出时二者不同；②所有表单的字段上限、默认尺寸、库存阈值等具体数值，按业务规则说明书 V1.1 执行，未在本文臆造。
