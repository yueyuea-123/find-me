# 核心页面验收清单 V1.1

## 客厅三维空间
- [ ] 页面进入后显示当前空间名称和家具场景。
- [ ] 家具模型加载中、加载失败均有明确状态。
- [ ] 点击家具后，场景和列表选中状态同步。
- [ ] 点击已选家具可进入对应家具管理。
- [ ] 家具/物品切换后，数据范围保持当前空间。
- [ ] 视角复位和适配屏幕操作有效。
- [ ] 空空间有明确添加家具入口。
- [ ] 底部面板不遮挡核心家具操作区域。

## 添加家具
- [ ] 未选择家具时不能提交。
- [ ] 长宽高字段有单位、输入限制和错误反馈。
- [ ] 移动、旋转、缩放工具状态互斥且明确。
- [ ] 模型调整后尺寸显示与模型表现一致。
- [ ] 返回时存在未保存修改会二次确认。
- [ ] 保存中禁止重复提交。
- [ ] 保存失败保留用户输入和模型调整。
- [ ] 保存成功回到原空间并选中新家具。

## 电视柜管理
- [ ] 结构管理和物品管理视图切换正确。
- [ ] 点击柜格时三维区域与清单同步选中。
- [ ] 每个收纳位置显示名称和物品数量。
- [ ] 空位置与有物品位置有不同状态。
- [ ] 可新增收纳位置。
- [ ] 删除含物品的位置前必须处理绑定物品。
- [ ] 结构和物品两种视图引用同一份数据。

## 全局一致性
- [ ] 导航栏、按钮、表单、卡片样式统一。
- [ ] 所有页面适配目标手机屏幕和安全区。
- [ ] 文案无截断、错字和占位符。
- [ ] 点击热区足够，不依赖极小图标触发。
- [ ] 图片缺失、网络异常、空数据均有兜底。
