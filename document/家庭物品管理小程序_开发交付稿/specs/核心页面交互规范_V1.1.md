# 核心页面交互规范 V1.1

> 本文基于当前已确定的产品方向整理：以房间三维视图承载家具，以家具收纳位置承载物品。本文明确页面行为和状态，不擅自增加智能识别、多人协作、自动盘点等未冻结能力。

## 1. 产品对象关系

```text
家庭
└── 空间（例如：客厅）
    └── 家具（例如：电视柜）
        └── 收纳位置（例如：左侧抽屉、上层隔板）
            └── 物品（例如：遥控器、纸巾）
```

### 对象边界
- 空间：承载家具的房间或区域，拥有独立三维视图。
- 家具：放置在空间中的实体模型，可设置尺寸与空间位置。
- 收纳位置：家具内部可管理的格子、抽屉、层板或柜格。
- 物品：用户记录的实体物件，可绑定到一个收纳位置。
- 库存：物品数量及余量提醒信息；库存提醒不改变物品与收纳位置的归属关系。

## 2. 页面 02：客厅三维空间

### 页面目标
让用户快速理解“房间里有哪些家具、家具在哪里、家具里放了什么”，并能进入家具管理或添加家具。

### 页面结构
1. 顶部导航：返回、空间名称、空间切换入口、更多操作。
2. 主视图区：房间三维场景，展示家具。
3. 场景工具：3D/视角控制、视图复位、适配屏幕。工具应收纳在边缘，不遮挡主要家具。
4. 底部内容面板：家具 / 物品切换。
5. 家具列表：当前空间家具缩略卡片。
6. 主操作：添加家具。

### 核心交互
| 操作 | 触发 | 结果 |
|---|---|---|
| 拖动空白场景 | 单指拖动 | 旋转/调整观察视角；需限制角度，避免翻转到不可用视角 |
| 双指手势 | 双指缩放 | 放大或缩小场景，设置最小/最大缩放范围 |
| 点击家具 | 点击模型 | 选中家具；显示选中描边/轻量信息标签 |
| 再次点击已选家具 | 点击模型 | 进入家具管理页 |
| 点击家具列表项 | 点击缩略卡片 | 场景定位并选中对应家具 |
| 点击“物品” | 切换标签 | 展示当前空间物品列表；每项显示物品名、数量、所属家具/收纳位置 |
| 点击“添加家具” | 主按钮 | 进入添加家具流程 |
| 点击视角复位 | 工具按钮 | 恢复默认相机位置和缩放 |
| 点击适配屏幕 | 工具按钮 | 将当前空间家具整体置于可视范围 |

### 状态要求
- 初次进入：显示默认视角、家具加载状态。
- 有家具：显示家具模型及底部家具列表。
- 空空间：显示空状态说明和“添加家具”主操作。
- 加载失败：保留页面框架，提示重试，不显示空白黑屏。
- 家具选中：显示明确选中态；未选中家具不显示高亮。
- 物品模式：隐藏或弱化家具列表，显示空间物品列表。
- 模型缺失：用统一占位模型和名称兜底，不影响家具数据操作。

### 视觉约束
- 三维场景是页面主视觉，不能被底部面板挤压成狭小窗口。
- 工具按钮保持一致尺寸、间距和点击热区。
- 选中反馈不能只依赖颜色，需同时使用轮廓/标签等方式。
- 底部面板应支持收起/展开；首版可采用固定高度加列表滚动，避免复杂手势冲突。

## 3. 页面 03：添加家具

### 页面目标
让用户选择家具并将其放入当前空间，完成基础尺寸与位置调整。

### 页面结构
1. 顶部导航：返回、标题、更多。
2. 家具预览区：当前选中的家具模型。
3. 家具选择：上一件/下一件或家具类型选择入口。
4. 尺寸表单：长、宽、高。
5. 位置调整：移动、旋转、缩放。
6. 底部固定操作：完成添加。

### 核心交互
| 操作 | 触发 | 结果 |
|---|---|---|
| 切换家具 | 左右切换/选择列表 | 更换预览模型；未确认前不写入空间 |
| 修改长宽高 | 点击尺寸行 | 打开数字输入；单位统一为 cm |
| 移动 | 点击移动工具 | 进入移动状态；拖动模型改变平面位置 |
| 旋转 | 点击旋转工具 | 进入旋转状态；通过拖动或角度步进旋转 |
| 缩放 | 点击缩放工具 | 进入缩放状态；保持模型比例，除非产品明确支持非等比缩放 |
| 完成添加 | 点击主按钮 | 校验尺寸和位置，保存家具并返回空间页 |
| 返回 | 点击返回 | 若存在未保存修改，提示“放弃修改/继续编辑” |

### 字段和校验建议
| 字段 | 单位 | 校验 |
|---|---|---|
| 长 | cm | 必填，必须大于 0，限制合理最大值 |
| 宽 | cm | 必填，必须大于 0，限制合理最大值 |
| 高 | cm | 必填，必须大于 0，限制合理最大值 |

具体最大值、默认尺寸和精度应由产品确认后写入业务规则，不在设计稿中臆造。

### 状态要求
- 模型加载中：预览区显示骨架/加载提示。
- 模型加载失败：显示占位图和重试入口。
- 未选择家具：完成按钮不可用。
- 尺寸无效：对应字段就地提示，不仅使用 toast。
- 保存中：按钮显示 loading 并防止重复提交。
- 保存成功：回到空间页，新增家具处于选中状态。
- 保存失败：保留当前输入，不清空用户调整。

### 交互约束
- 移动、旋转、缩放必须有明确当前工具状态。
- 同一时间只允许一个变换工具处于激活状态。
- 模型拖动与页面滚动需隔离，避免手势冲突。
- 尺寸编辑与模型缩放要定义同步关系：修改尺寸应更新模型比例；是否允许拖拽缩放反向更新尺寸，需在开发前确认。

## 4. 页面 04：电视柜管理

### 页面目标
将电视柜的内部空间拆成可识别、可管理的收纳位置，并查看每个位置中的物品。

### 页面结构
1. 顶部导航：返回、家具名称、更多。
2. 家具外观区：电视柜整体图/模型。
3. 模式切换：结构管理 / 物品管理。
4. 内部结构区：抽屉、层板、柜格等收纳位置。
5. 收纳位置清单：名称、物品数量、进入详情入口。
6. 添加收纳位置：创建新的内部位置。

### 核心交互
| 操作 | 结构管理 | 物品管理 |
|---|---|---|
| 点击某个柜格 | 选中柜格并显示边界/名称 | 展示该位置内的物品 |
| 点击位置清单 | 定位并选中对应柜格 | 打开该位置物品列表 |
| 添加收纳位置 | 创建位置并设置名称/类型 | 不显示结构创建操作 |
| 编辑位置 | 修改名称、类型、位置关系 | 从物品列表进入位置编辑 |
| 删除位置 | 有物品时先提示迁移或清空 | 不允许静默删除已绑定物品 |

### 收纳位置数据建议
- id：唯一标识
- furniture_id：所属家具
- name：用户可读名称，例如“左侧抽屉”
- type：drawer / shelf / compartment / cabinet 等内部类型枚举
- sort_order：展示顺序
- geometry_ref：可选，关联三维模型中的区域标识
- created_at / updated_at：创建和更新时间

### 关键业务规则
1. 每个收纳位置必须属于一件家具。
2. 一个物品在同一时刻只能有一个当前存放位置；如需多位置数量拆分，属于后续数据模型扩展，首版不默认支持。
3. 删除含有物品的收纳位置前，必须让用户处理其中物品：迁移到其他位置或先解除位置绑定。
4. 物品数量为 0 时，位置仍可保留。
5. 结构管理与物品管理是同一家具数据的两种视图，不应复制出两套互不关联的数据。

### 状态要求
- 无收纳位置：显示空状态及“添加收纳位置”。
- 位置选中：三维柜体区域和清单同步高亮。
- 位置为空：显示“暂无物品”及添加物品入口。
- 位置有物品：显示物品数量和物品摘要。
- 删除受阻：说明该位置仍有物品，并提供迁移操作入口。

## 5. 跨页面导航和数据一致性

| 起点 | 操作 | 终点 | 必须保持的数据 |
|---|---|---|---|
| 首页 | 点击客厅 | 客厅空间 | 当前空间 ID |
| 客厅空间 | 点击家具 | 电视柜管理/家具详情 | 家具 ID、空间 ID |
| 客厅空间 | 添加家具 | 添加家具 | 空间 ID |
| 电视柜管理 | 点击收纳位置 | 位置物品列表/管理 | 家具 ID、位置 ID |
| 位置管理 | 添加物品 | 添加物品 | 当前家具 ID、位置 ID |
| 我的物品 | 点击物品 | 物品详情 | 物品 ID |
| 物品详情 | 编辑 | 编辑物品 | 物品 ID、当前存放位置 |

## 6. 首版不应擅自增加的交互
- 自动识别家具尺寸或房间结构。
- 多人实时共同编辑三维场景。
- 家具碰撞检测和复杂物理模拟。
- 多个物品位置拆分及数量分摊。
- 自动生成全屋装修方案。
- 未经产品确认的复杂 AR/扫描流程。
