## 三、缺失的"操作页面"清单

除状态外，以下为**被现有文档/代码引用、但 8 张高保真稿未覆盖的操作页面**，建议补设计或明确"沿用通用表单样式"：

| 操作页面 | 来源依据 | 建议 |
|---|---|---|
| 空间管理 / 新增空间 | 首页"管理空间"入口；pages/space | 补页面稿或沿用列表+表单通用样式 |
| 更多操作菜单 | 首页"更多"入口 | 定义菜单项（未冻结功能不入） |
| 分类/存放位置选择器 | 05 添加物品字段 | 补选择器弹层稿 |
| 新增/编辑收纳位置表单 | 04 + 交互规范 §4 字段建议 | 补表单稿 |
| 编辑物品页 | 07"编辑"入口（复用 05） | 明确与 05 共用，无需单独出图 |
| 入库/消耗/调整表单 | 08 + inventory-detail | 补表单稿或沿用通用样式 |
| 二次确认弹窗（删除/放弃修改/删位置） | UI 规范 + 各页状态要求 | 补一套通用 ConfirmDialog 稿 |
| 通用空态 / 加载态 / 错误态 / Toast | UI 组件规范 §3 | 补一套通用状态稿 |

## 四、优先级建议

1. **高**：二次确认弹窗、就地错误态、加载/空/错误通用状态——交互规范与验收清单已明确要求，补齐后可闭环验收清单"图片缺失、网络异常、空数据均有兜底"。
2. **中**：05 位置选择器、04 收纳位置表单、08 库存表单——涉及主流程内的下一步操作。
3. **低 / 待产品确认**：借出态、自定义标签、更多菜单——涉及项目实际能力，但高保真稿范围未包含，需产品确认是否纳入视觉基线。

> 本盘点只核对覆盖、不下"必须重做"结论。若产品确认"状态样式由 `UI组件与视觉规范 V1.1` 派生、不单独出图"，则第四、五节的 ⚠️ 项可在开发规格中标注为"按组件规范实现"，无需补 PNG。
