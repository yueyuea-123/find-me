# 小程序 UI 组件与视觉规范 V1.1

## 1. 设计基础

| 项目 | 规范 |
|---|---|
| 设计逻辑宽度 | 750rpx |
| 输出倍率 | 2x |
| 页面基底 | 暖白/浅米色 |
| 主色 | 鼠尾草绿 |
| 主文字 | 深灰绿黑 |
| 次级文字 | 中性灰 |
| 卡片 | 白色、柔和阴影、圆角 |
| 分割线 | 极浅暖灰 |
| 危险操作 | 低饱和红色，仅用于删除等危险操作 |

颜色变量以项目根目录 `design-tokens.json` 为准。开发时集中定义，不在页面样式中散落硬编码。

## 2. 字体层级

| 层级 | 建议字号 | 用途 |
|---|---:|---|
| 页面标题 | 36rpx | 顶部标题 |
| 区块标题 | 30rpx | 页面模块标题 |
| 正文 | 24rpx | 字段、列表主文案 |
| 辅助文字 | 20rpx | 数量、说明、时间 |
| 按钮 | 26–28rpx | 主/次操作 |

中文字体使用系统可用无衬线字体栈。避免用图片承载正文文字。

| 组件 | 用途 | 必备状态 |
|---|---|---|
| AppNavigationBar | 顶部导航 | 默认、返回、标题居中 |
| BottomTabBar | 底部一级导航 | 默认、选中 |
| PrimaryButton | 主操作 | 默认、按下、禁用、加载 |
| SecondaryButton | 次操作 | 默认、按下、禁用 |
| SegmentedTabs | 双视图切换 | 默认、选中、禁用 |
| FilterChip | 分类筛选 | 默认、选中 |
| FurnitureCard | 家具缩略卡片 | 默认、选中、加载失败 |
| ItemCard | 物品卡片 | 默认、选中、缺图 |
| StorageLocationRow | 收纳位置行 | 默认、选中、空位置、有物品 |
| FormField | 表单字段 | 默认、聚焦、错误、禁用 |

## 4. 组件行为约束
- 所有按钮均应有按下反馈和明确点击热区。
- 禁用态必须有视觉区分，且不可触发事件。
- 加载态避免重复提交。
- 错误信息优先就地展示；toast 仅作为辅助反馈。
- 列表卡片整块可点击时，内部按钮需阻止事件冒泡。
- 删除、清空、放弃未保存修改等不可逆操作需要确认。
- 图标风格统一，避免 emoji 与线性图标混用。

## 5. 页面安全区与滚动
- 顶部状态栏、安全区由小程序原生环境适配，不在业务内容中重复模拟。
- 底部 TabBar 与系统安全区分开处理。
- 长列表只在内容区域滚动，顶部导航和底部导航保持稳定。
- 固定底部主按钮时，内容区预留足够底部 padding，避免遮挡最后一项。
- 三维画布触摸事件需与页面滚动、底部面板拖动进行手势仲裁。

## 6. 图片与模型资源规范
- 家具缩略图与三维模型使用同一家具 ID 关联。
- 物品图片使用统一比例和裁切规则；缺图时使用统一占位图。
- 三维模型需提供统一坐标原点、单位、朝向和缩放约定。
- 模型资源需记录版本、格式、尺寸和缩略图。
- 参考拼图中裁切出的图片仅供视觉占位，不作为正式商品素材或可编辑 3D 模型。
