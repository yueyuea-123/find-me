# 家庭物品管理小程序｜开发交付稿（设计基线 V1.0）

## 交付内容
- `screens/`：8 张独立高清 PNG，1500 × 3248，按 750rpx 设计宽度、2x 导出
- `source/`：对应的 SVG 矢量页面源文件，可继续编辑
- `assets/`：从用户提供的原始参考拼图中裁切的家具、房间和物品视觉素材
- `design-tokens.json`：颜色、字号、圆角、间距等设计变量

## 页面清单
1. 01-首页
2. 02-客厅空间
3. 03-添加家具
4. 04-电视柜管理
5. 05-添加物品
6. 06-我的物品
7. 07-物品详情
8. 08-库存管理

## 设计规范
- 设计画布：750 × 1624（rpx）
- 输出图片：1500 × 3248（2x）
- 主色：鼠尾草绿；背景：暖白/浅米色
- 卡片圆角：24rpx；主要按钮圆角：44rpx
- 页面采用统一状态栏、导航栏、底部安全区和组件间距

## 核心交互约定（开发实现需遵循）
- 首页：空间入口、添加物品、库存管理入口
- 客厅空间：家具/物品视图切换；点击家具进入家具管理；添加家具进入家具选择
- 添加家具：选择家具模型、设置长宽高、移动/旋转/缩放、确认添加
- 电视柜管理：结构管理与物品管理切换；按隔板/抽屉/柜格管理收纳位置
- 添加物品：填写名称、分类、数量、存放位置、备注
- 我的物品：搜索、分类筛选、物品卡片进入详情
- 物品详情：查看数量、位置、添加时间、备注和位置历史；支持编辑/删除
- 库存管理：按全部/易耗品/长期用品筛选，展示余量与补货提醒

## 重要交付边界
本版本是基于用户提供的 8 页参考拼图进行的矢量化 UI 重绘，用于页面布局、组件和视觉规范对照。
其中房间、家具和商品图仍使用参考图裁切素材；并非可编辑的真实 3D 模型，也不包含微信小程序业务代码、接口、数据模型或可运行的 3D 操作。
进入正式开发前，需由产品确认字段、状态和交互细节，并替换为正式授权的高清 3D/商品素材。
