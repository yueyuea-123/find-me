# 模拟器基线留档 V1.0

> **留档日期**：2026-11-24
> **替代说明**：按用户指示，本轮以微信开发者工具**模拟器**留档代替真机基线（原计划小米 13 真机基线，推迟到提审前补测）。
> **口径限制**：模拟器数据反映 macOS 开发者工具的运行期表现，**不代表真机帧率与低端机表现**。帧率（FPS）在模拟器中无法可靠测量，本文以「手势响应耗时 / 渲染提交耗时」作为代理指标；真机帧率基线仍需在小米 13 上补测（见档案待办表）。

## 3. 页面加载耗时（模拟器，中位数 / 3 次）

| 页面 | 耗时 | 就绪判据 |
|---|---|---|
| 首页 index | **365 ms** | 页面挂载完成 |
| 空间页 room | **355 ms** | 页面挂载 + 房间列表非空 |
| 三维房间 room3d | **368 ms** | 页面挂载 + GL 渲染器就绪 + view=3d 无 glError + 家具列表非空 |

注：为「编译完成后」的运行期 reLaunch 加载，不含首次编译与代码包下载；三次样本离散度 < 25 ms，稳定。

## 4. 交互响应耗时（代理指标，中位数）

| 指标 | 耗时 | 说明 |
|---|---|---|
| 单指拖拽手势（pick→dragDelta→抬手落盘→loadData） | **148 ms** | 含 pick 全屏扫描（纯 JS 逐点探测，真机触摸不经过此路径）；手势处理本身为毫秒级 |
| 拖空白转视角手势（onTouch→orbit→渲染提交） | **6 ms** | — |
| 渲染提交（_safeRender 单次） | **1–3 ms** | JS 侧渲染指令提交，非 GPU 帧耗时 |
