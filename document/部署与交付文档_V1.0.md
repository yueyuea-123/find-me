```
iteam/
├─ miniprogram/              小程序前端（21 个页面 + utils）

   ├─ check_and_score.py     静态质量门禁
   └─ smoke-test.js          运行时冒烟门禁
```

## 三、部署步骤

### 3.1 首次部署（已完成，供复现）

1. 微信开发者工具导入 `iteam/`，AppID 以 `project.config.json` 实际配置为准。
2. 确认 `miniprogram/envList.js` 中环境 ID 正确；依赖版本（wx-server-sdk、基础库）以官方当前稳定版为准，不在文档写死旧版本号。
3. 云开发控制台创建 13 个集合：`users / spaces / rooms / furniture / nodes / items / movements / inventory / transactions / alerts / backups / sys_logs / tasks`。
4. 所有集合权限设为「仅创建者可读写」（PRIVATE）。前端不直连数据库，全部经云函数（服务端管理员权限）。
5. 部署 6 个云函数：右键每个函数目录 → 上传并部署（云端安装依赖），或在开发者工具 CLI 执行。
6. 为 `backupService` 配置定时触发器：`0 0 3 * * * *`（每天 03:00，7 段 Cron，秒 分 时 日 月 星期 年）。
7. 配置管理员：在 `adminService` 环境变量 `ADMIN_OPENIDS` 填入管理员 openid（多个用逗号分隔），或在 `users` 集合将指定用户 role 改为 `admin`。

### 3.2 日常部署

- 前端改动：开发者工具直接编译预览，无需重新部署云函数。
- 云函数改动：仅重新部署变更的函数。
- 每次改动后跑 `qa/` 下两道门禁。

## 四、数据隔离与安全

- 云函数从 `cloud.getWXContext().OPENID` 取身份，忽略客户端传入的 openid；所有查询强制带 openid 条件。
- 集合权限 PRIVATE：客户端 SDK 直连数据库一律拒绝，仅云函数（服务端权限）可读写。
- 照片路径 `photos/{openid}/{roomId}/{photoId}`，读取用短时链接；后台不返回照片内容。
- 错误上报只发文案与堆栈，不发家庭照片或物品明细。
- **背景核查**：本环境个人版当前计费未激活（EnvActivated=no、EnvCharged=yes）；后续用量与费用以腾讯云官方账单为准。

## 五、备份与恢复

| 项 | 策略 |
|---|---|
| 自动备份 | 每日 03:00 遍历活跃用户，各生成一份快照（type=auto） |
| 手动备份 | 我的 → 备份与恢复 → 创建备份（type=manual） |
| 保留策略 | 默认保留全部；如需限额，可在 backups 集合按 createdAt 清理旧记录 |
| 恢复 | 选择备份 → 恢复；系统先自动快照当前状态（可回滚）再覆盖 |
| 恢复验证 | 部署日志见测试记录的"云端调用验证"章节 |

## 六、故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 首页显示"本地模式" | 云函数未部署或登录失败 | 检查 userLogin 部署与云开发环境是否开通 |
| 有变更待同步长期不消失 | 云端写入失败 | 我的→立即同步；仍失败看 sys_logs 集合 |
| 三维显示列表 | WebGL 不可用或渲染异常 | 属预期降级，列表功能完整；换设备或更新基础库再试 |
| 管理后台提示无权限 | 非 admin 角色 | 在 users 集合把该 openid 的 role 改为 admin |
| 定时备份未生成 | 触发器未创建或 users 无 active 用户 | 检查触发器配置与 users 集合 |

## 八、V1.2（CR-001）交付口径补充

- **主路径**：三维空间以手动自由编辑为主——用户手动录入房间宽/深/高，选空白房间或典型场景模板（卧室/客厅/卫生间，静态预置于 `constants.js` 的 `ROOM_TEMPLATES`）作为起点，添加/移动/旋转/缩放模型并绑定物品；照片上传与建模任务降级为可选素材，不作为验收阻断项。
- **数据字段**：房间新增 `layout/source/templateKey`，家具变换统一 Y-up/米，模型—物品绑定单源复用 `nodes.furnitureId` + `items.currentNodeId`（不新增 `bindings` 双绑定源）；详见《数据架构与接口契约》§2.3 与 design.md §5。
- **模型资源清单**：当前家具为程序化标准模型库（`constants.js` 的 `FURNITURE_LIB`），无第三方模型与商用授权依赖；后续引入外部 GLB/glTF 模型时须补来源与授权清单。
- **质量门禁**：静态 ≥90/100 且 0 P0（D8 已纳入 CR-001 方法/字段检查）；运行时冒烟 56/56（含 CR-001 八条断言）、21/21 页零异常。三维手势手感与 WebGL 交互须真机 AC 补充，自动化不覆盖。

> 云函数 API、安全规则、定时任务语法、基础库版本要求以微信官方与腾讯云 CloudBase 官方文档最新说明为准。
