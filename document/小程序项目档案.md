> **口径基线**：本文档以《当前基线（唯一口径）V1.1》为唯一依据。本文与基线冲突时，以基线为准；代码与本文不一致处，见 `document/文档-实现对账清单_V1.0.md` 与整改排期逐批收敛。

## 一、项目概况

| 项 | 内容 |
|---|---|
| 项目名 | 三维室内空间与家庭物品管理小程序（居所收纳） |
| 主体类型 | 个人（MVP 个人单用户） |
| 数据形态 | **纯本地存储**（`wx.Storage`）。云同步、云备份、云照片、云端管理后台均不在交付范围（基线 §1、§6） |
| AppID / 环境 | 测试号即可；如使用自有 AppID，请确保未强制开通云开发。云端环境历史上曾配置但已从交付链路摘除，不作为交付依赖 |
| 上位基线 | **《当前基线（唯一口径）V1.1》** > 产品总纲 V1.0 > 业务规则说明书 V1.1 > PRD V1.1 |
| 范围 | 基线裁剪后：本地建档、查找、位置与库存管理、移动历史、本地提醒、本地备份导出/恢复、照片本地选图与展示。云端相关 PRD-001~004/030~033 不在本次验收范围 |
| 归属模型 | 空间 → 家具 → 物品。物品必填 `spaceId`；锚点 `anchorType` 三态互斥（`furniture` / `space_direct` / `unplaced`）；物品不持有坐标与 `roomId`，房间归属由所在家具推导 |
| 当前阶段 | B1 文档对账、B2 云端下线、B3 归属模型、B4 三维收口、B5 结构清理已完成；结构门禁全绿（静态 100/100、冒烟 78/78、v13 61/61、drag 26/26、item-rules 14/14）。待 B6 物理真机验收与 B7 提审准备 |

## 二、技术栈

| 项 | 内容 |
|---|---|
| 框架 | 微信原生小程序（WXML/WXSS/JS） |
| 后端 | **纯本地**：`wx.Storage` 为唯一数据源；无云端持久化、无云函数调用 |
| 云数据库 | **【已移出范围】** 历史上曾建 13 集合，已从交付链路摘除，不作为交付依赖 |
| 云函数 | **【已移出范围】** 历史上 6 个云函数（userLogin / dataSync / photoService / backupService / adminService / reportError）已从交付链路摘除，源码保留但不被引用 |
| 存储键 | `home3d_store_v1`（主数据）、`home3d_tombstones_v1`（删除墓碑），版本 version=1 |
| 云同步 | **【已移出范围】** `utils/cloud-sync.js` 将在 B2 摘除引用，当前启动期不再调用 |
| 备份 | 本地备份导出/恢复（基线保留能力）；云端定时快照 **【已移出范围】** |
| 三维 | Three.js r108 适配版 + 8 件白膜 GLB，置于 `package3d` 分包（`renderer.js` / `vendor/` / `assets/furniture/`），按需 `wx.loadSubpackage` 加载；失败降级列表。`utils/webgl-renderer.js`、`room-renderer.js` 为历史无引用文件（B5 清理） |
| 单位约定 | Y-up，单位米；家具三维对象与逻辑收纳节点解耦（BR-009） |
| 基础库 | 未锁定具体下限，提审前需以官方文档核实；开发者工具模拟器实测 SDK 3.18.0 |
| 包体 | 主包 21 页约 1.44 MB（≤2 MB）+ `package3d` 分包约 1.09 MB（≤2 MB，含白膜资产与带色版备份）。2026-11-22 起已分包；纯资源分包的 `preloadRule` 被新版开发者工具校验拒绝，已移除，改为按需加载 |
