## 二、技术栈

| 项 | 内容 |
|---|---|
| 框架 | 微信原生小程序（WXML/WXSS/JS） |
| 后端 | 离线优先：本地 `wx.Storage` 为主数据源 + CloudBase 云端持久化；前端全走云函数，不直连数据库 |
| 云数据库 | NoSQL 13 集合已创建并设为 PRIVATE（仅云函数服务端可读写），openid 隔离 |
| 云函数 | 6 个已部署并 Active：userLogin / dataSync / photoService / backupService / adminService / reportError |
| 存储键 | `home3d_store_v1`（主数据）、`home3d_tombstones_v1`（删除墓碑），版本 version=1 |
| 云同步 | `utils/cloud-sync.js`：登录→未推送变更先推送→拉快照→后台推送（30s 周期 + onHide/onShow）；按变更序号保护同步期间的新编辑，失败保留 dirty；`dataSync` 按 `{openid,id}` 幂等写入并在 pull 时清理历史重复副本 |
| 备份 | 每日 03:00 定时触发器遍历活跃用户自动快照；恢复前自动建回滚快照 |
| 三维 | Three.js r108 适配版 + 8 件白膜 GLB，置于 `package3d` 分包（`renderer.js` / `vendor/` / `assets/furniture/`），按需 `wx.loadSubpackage` 加载；失败降级列表。`utils/webgl-renderer.js`、`room-renderer.js` 为历史无引用文件 |
| 单位约定 | Y-up，单位米；家具三维对象与逻辑收纳节点解耦（BR-009） |
| 基础库 | 未锁定具体下限，提审前需以官方文档核实；开发者工具模拟器实测 SDK 3.18.0 |
| 包体 | 主包 21 页约 1.44 MB（≤2 MB）+ `package3d` 分包约 1.09 MB（≤2 MB，含白膜资产与带色版备份）；6 个云函数独立部署在云端。2026-11-22 起已分包；纯资源分包的 `preloadRule` 被新版开发者工具校验拒绝，已移除，改为按需加载 |
