## 一、总体交互原则（规范 V1.0 §2.3 / §11）

1. **单一主视图**：不设专业三维编辑器式多面板工作台，也不设浏览/编辑/收纳模式分段；顶部为房间名与基础操作，中部为三维视图，选中信息以底部抽屉叠加在三维窗口下沿，三维场景保持可见。
2. **固定等距视角**：正交相机 yaw=π/4、pitch=π/5.5 固定，不提供自由旋转/平移；双指仅有限缩放视图（不改变等距角度），「复位视图」回到默认比例。
3. **家具是物品入口**：点家具先选中并展开底部抽屉，在抽屉内查看收纳节点、节点物品数与物品，再进入「查看全部 / 添加物品」；物品不因绑定而需要独立三维模型。
4. **预览不写库、抬手一次落盘**：拖动期间只改渲染内存（`previewMove` 不改 `_raw`），`touchend` 一次性写 `store`。
5. **越界钳制**：位置按房间半宽/半深扣家具半尺寸钳制，旋转归一化到 `[0, 2π)`。
6. **失败可降级**：WebGL 失败、canvas 取不到、渲染异常、GLB 缺失一律切列表视图，家具与物品管理不中断。
7. **关系分离与数据保护**：家具展示属性（位置/朝向/尺寸/外观）与物品存放关系（逻辑节点）分开管理；删除家具不静默删除物品记录。

## 二、输入与拾取基座

| 环节 | 规则 | 代码依据 |
| --- | --- | --- |
| 事件绑定 | canvas 使用 `catchtouchstart/move/end`，阻止页面滚动抢占手势 | `room3d.wxml` |
| 坐标换算 | 真机 canvas 事件 `x/y` 已是画布内坐标，直接采用；缺 `x/y` 的模拟器用 `pageX/pageY − rect` 兜底 | `_touchPoint` |
| rect 同步 | 分段页可滚动，`onPageScroll` 与各触摸开始时重取 canvas 偏移 | `_syncCanvasRect` |
| 拾取 pick | 屏幕投影包围盒命中，框内取离中心最近者，返回渲染原始索引 | `renderer.js:pick` |
| 移动阈值 | 单指位移 `|dx|+|dy| > 5px` 判为拖动，同时取消长按计时 | `onTouchMove` |
| 长按阈值 | 按住家具 600ms 且未移动 → 删除二次确认 | `onTouchStart` 的 `_lpTimer` |
| 双指优先级 | 第二指落下即清空单指拖动标识（`_dragFid=''`）、设 `_moved=true` | `onTouchStart` 双指分支 |

## 三、交互矩阵（单一主视图）

| 操作 | 行为 |
| --- | --- |
| 单指短按家具 | 选中家具，高亮环 + 底部抽屉（家具名、物品数、收纳节点及各节点有效物品数），**不跳页** |
| 单指拖家具 | 跟手预览移动，抬手落盘位置（无需切模式） |
| 单指短按空白 | 取消选中并关闭抽屉，高亮环同步清除 |
| 单指拖空白 | 无操作（视角固定，不旋转/不平移、不移动家具） |
| 双指捏合 | 有限缩放视图（正交视野），**不改变家具尺寸、不旋转视角** |
| 旋转家具 | 视图内按钮 ↶/↷，每次 ±90°，立即落盘 |
| 长按家具 | 删除二次确认（提示物品归属，数据层关联保护） |
| ＋ 家具 | 展开/收起家具模型库抽屉，点选类别即添加占位家具 |
| 添加物品 | 抽屉操作：新建物品（继承当前家具/节点）或从已有物品中选择（绑定/改存放位置） |
| 查看物品 | 抽屉内直接展示当前节点物品；「查看全部」进入家具详情（关联物品列表 + 逻辑收纳节点） |
| 抽屉收起/关闭 | 点抽屉标题栏收起/展开；✕ 关闭面板，不改变任何业务数据 |
| 复位视图 | 恢复默认视图比例 |
| 列表（降级） | 手动切整页列表；WebGL 不可用时自动降级 |

## 四、逐交互逻辑链

### 4.1 选中、短按与底部抽屉
- touchstart 命中家具即 `selectIndex(idx)`：同步高亮环、选中卡数据（含 `bindCount`、`bindings`）与抽屉节点内容。
- touchend 判为短按（未移动、未触发长按）且命中：`openSheet()` 展开底部抽屉，**不自动跳页**。
- touchend 短按空白：`clearSel()` 取消选中并关闭抽屉。
- 抽屉标题栏点按收起/展开，✕ 关闭面板；关闭只改视图状态，不改业务数据。
- 抽屉内节点 chip 点按切换 `activeNodeId`，面板刷新为该节点直接关联的物品（最多显示 5 件，完整列表走「查看全部」）。
- 切换选中家具时，抽屉节点与物品内容同步刷新；首次进入默认选中第一件家具但抽屉保持收起，由用户点家具后展开。

### 4.2 移动（单指拖家具）
1. touchstart 记录起点 `_sx/_sy`、命中索引 `_hitIdx`、家具 id `_dragFid`。
2. touchmove 超阈值 → `dragDelta(dx,dy)` 把像素位移换算为地面世界位移（正交相机 `worldPerPixel=2·span/高度`，纵向按 `1/sin(pitch)` 补偿做到跟手）。
3. `previewMove(idx,x,z)` 钳制到房间边界并移动渲染实例；浮标实时刷新 X/Z（不写库）。
4. touchend 一次性写 `position`，toast「位置已保存」。

### 4.3 缩放视图（双指）
- 双指指距变化时调用 `zoom(startDist − currentDist)`；张开放大、捏合缩小，`zoom` 在渲染器内钳制 `[0.7, 2.2]`。
- 不改变相机 yaw/pitch（等距角度恒定），不修改家具 `size`。
- 家具尺寸使用模型预设规格；不提供自由缩放/轴向缩放（规范 §4.4）。

### 4.4 旋转家具（视图内按钮）
- 选中即显示 ↶ / ↷（`cover-view`，canvas 原生组件之上的覆盖层）。
- 每次固定 ±90°（π/2），归一化到 `[0, 2π)`，立即落盘并 toast。
- 不提供双指扭转：真机扭角难以精确控制。

### 4.5 删除
- 长按或卡片「删除家具」→ `showModal` 二次确认，明确告知关联物品数量与「物品记录不会删除」。
- 数据层 `HAS_LINKS` 关联保护：有子节点或物品则阻断，提示先迁移存放位置。
- **禁止因删除家具模型而静默丢失物品记录**。

### 4.6 家具库（按需）
- 默认收起，点工具条「＋ 家具」展开抽屉；点类别即从库中添加占位家具到默认位置（可再拖动）。
- 抽屉内「建档家具」进入详细建档页。

### 4.7 物品绑定（两路径，均继承当前上下文）
- 抽屉「＋ 添加物品」→ `addItemAtActiveNode()` 进入 `item-edit`，预选当前节点；未选具体节点时回退家具根节点。
- 抽屉「关联已有」/ 操作表「从已有物品中选择」→ `openBindPicker` 列出全部未结束档案及当前位置；点选调用 `store.moveItem(id, { locationStatus:'at_home', currentNodeId:当前节点 })`，重复点选不产生流水。
- 抽屉「查看全部」→ `furniture-detail`，展示关联物品与逻辑节点，支持进入物品详情、改存放位置、新增/删除节点。
- 节点计数调用 `store.itemsInNode(id)`，已结束管理（归档）物品不计入默认数量。

## 五、状态与落盘时机

| 状态量 | 生命周期 | 作用 |
| --- | --- | --- |
| `_sx/_sy`、`_moved`、`_dragFid`、`_hitIdx` | 单指手势始 → end 重置 | 单指拖动状态机 |
| `_pinch/_pinchStart` | 双指始 → end 重置 | 视图缩放基准 |
| `_lpTimer/_lpFired` | 长按定时 | 移动/双指/end 均清除，防误删 |
| `_previewPos` | move 期 → end 落盘 | 仅当预览存在才写库 |
| `sheetOpen/sheetCollapsed` | 点家具展开 → ✕ 关闭 / 点标题栏收起 | 纯视图状态，不改业务数据 |
| `sheetNodes/activeNodeId/nodeItems` | 选中家具或节点时刷新 | 抽屉节点列表、当前节点及其直接关联物品 |

**落盘判定（touchend 优先级）**：
1. 已移动 && 有拖动家具 && 有位置预览 → 写 `position`；
2. 否则短按命中家具 → 保持选中并展开底部抽屉；短按空白 → 取消选中并关闭抽屉；
3. 删除/旋转/绑定走各自独立处理函数，与手势状态机互不干扰。

## 六、反馈机制

- **浮标**：拖动实时显示「已选：名称 · X / Z」。
- **视图内旋转按钮**：选中后窗口右上 ↶ / ↷。
- **覆盖层用 `cover-view`**：canvas 是原生组件，浮标/提示/旋转按钮/底部抽屉均用 `cover-view` 包裹；`cover-view` 不支持 `gap`/`box-shadow`，间距用 margin/边框。
- **底部抽屉**：家具名称与有效物品总数、收纳节点及各节点物品数、当前节点物品、＋添加物品 / 查看全部 / 关联已有 / 更多；标题栏可收起，✕ 关闭。
- **按需面板**：家具库抽屉（`showLib`）、从已有物品选择（`showBindPicker`）。
- **提示 hint**：`点家具查看与添加物品 · 拖动摆放 · 双指缩放视图 · 按钮旋转 90° · 长按删除`。
- **Toast**：位置已保存 / 已绑定到「X」/ 已在该位置 / 旋转 90° / 关联阻断提示。

## 七、边界、异常与降级

| 类别 | 场景 | 处理 |
| --- | --- | --- |
| 越界钳制 | 家具移出房间 | 按房间半宽/半深扣家具半尺寸钳制；家具大于房间时居中 0 |
| 关联保护 | 删除含绑定的家具 | 阻断并提示先迁移；物品记录保留 |
| WebGL 降级 | 初始化失败/节点取不到/渲染抛异常 | `_safeGL` 收口，置 `glError`、`view='list'` 整页切列表 |
| 资产缺失 | GLB 加载失败 | 显式弹窗告知，给出「切列表 / 删除小程序刷新资源包」路径 |
| 生命周期 | 切列表销毁 canvas | 清引用；切回重建；`_initGL` 带 10 次重试与加锁防双初始化 |

## 八、验收对齐（规范 V1.0 §9）

1. 打开房间看到固定等距三维场景 —— 相机锁定，`orbit/pan` 页面不调用。
2. 从家具库添加家具 —— `＋ 家具` 抽屉点选。
3. 场景中选中家具 —— 短按选中 + 高亮环 + 底部抽屉。
4. 调整家具位置 —— 拖动跟手、抬手落盘、越界钳制。
5. 调整家具朝向 —— 视图内按钮 ±90°。
6. 查看名称及绑定物品数量 —— 抽屉标题 `bindings.items.length`，节点 chip 显示各节点 `itemCount`。
7. 将已有物品绑定到家具 —— 从已有物品选择面板（`moveItem`）。
8. 从家具入口查看绑定物品 —— 抽屉当前节点直接展示物品，「查看全部」进家具详情。
9. 修改物品存放家具 —— 绑定面板重复选择或移动页。
10. 删除家具不静默删物品 —— `HAS_LINKS` 阻断 + toast 文案。
11. 三维不可用仍可列表管理 —— 自动/手动列表降级。
