## 四、验证覆盖

- **功能闭环**：空间 → 房间 → 照片/建模任务 → 三维查看/列表降级 → 家具 → 多级收纳节点 → 物品档案 → 移动历史 → 库存交易 → 提醒 → 隐私/重置。
- **业务规则**：事实与预测分离（AI 候选不自动成为事实）、失败可降级（WebGL 不可用自动切列表）、三维对象与逻辑位置解耦（换模型不动节点）、位置历史可追溯、库存不为负、提醒周期自动恢复。
- **隐私**：全本地 `wx.Storage`，无第三方传输；浏览器端识别服务仅属技术验证载体，不进入小程序运行时。
