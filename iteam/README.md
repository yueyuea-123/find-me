# 居所收纳 · 三维室内空间与家庭物品管理小程序（MVP）

微信原生小程序，个人单用户本地存储版本。**开箱即用，无需配置云开发环境**。

## 一、快速开始

1. 打开微信开发者工具 → 导入项目 → 选择本目录 `iteam/`。
2. AppID 可选择「测试号」；如使用自有 AppID，请确保未强制开通云开发。
3. 编译运行。首次启动会自动填充一套演示数据（1 个空间 / 1 个房间 / 3 件家具 / 5 件物品）。
4. 在「我的 → 清空数据」可重置为空库，从零体验完整建档流程。

> 本版本全部数据保存在微信本地缓存 `home3d_store_v1`，不上传任何服务器。清除小程序缓存会丢失数据。

## 二、功能地图

| 模块 | 页面 | 说明 |
|---|---|---|
| 空间 | `pages/space` | 空间新增/改名/归档/切换 |
| 房间 | `pages/room` | 房间新增/尺寸定标/建模任务状态入口 |
| 照片与建模 | `pages/photos`、`pages/task` | 照片增删；任务状态与失败后手动降级（本地版不虚报建模成功） |
| 三维 | `pages/room3d` | 轻量 WebGL 房间渲染，单指旋转/双指缩放/点选家具；WebGL 不可用时自动切列表 |
| 家具 | `pages/furniture-edit`、`pages/furniture-detail` | 家具增删改、外观与位置、换模型不动逻辑节点 |
| 收纳节点 | `pages/node` | 多级收纳树、排序、关联物品 |
| 物品 | `pages/item-list`、`pages/item-edit`、`pages/item-detail` | 搜索筛选、单件/连续建档、完成度、结束与恢复 |
| 移动 | `pages/move`、`pages/history` | 首次确认/移出/归还/移动，全量历史可追溯 |
| 库存 | `pages/inventory`、`pages/inventory-detail` | 入库/消耗/调整、交易流水、库存不为负 |
| 提醒 | `pages/alerts` | 低库存提醒开启、忽略、达标自动恢复 |
| 我的 | `pages/profile` | 隐私说明、重置演示数据 |

## 三、技术约定

- **数据层**：`utils/store.js`，统一返回 `{ ok: true, data? }` / `{ ok: false, error }`；所有写操作内存变更后一次性落盘，保证位置与历史同一事务。
- **业务规则**：实现 BR-001~015 与 TBD-001~008，来源见产品文档目录的业务规则说明书与范围冻结清单。
- **三维**：Y-up、单位米；三维家具对象与逻辑收纳节点解耦；AI 候选与用户确认事实分离。
- **可替换性**：后续接云端时只需替换 `utils/store.js`，页面层无需改动。

- 平台规则与基础库版本要求以微信官方最新文档为准。
