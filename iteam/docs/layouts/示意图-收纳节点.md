# 示意图：收纳节点（UI-009 · pages/node/node）

> 依据：`pages/node/node.wxml` + `.js`。多级收纳结构与关联保护（MVP-013~015）。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ 节点信息卡：名称 + 完整路径      │
│   [重命名][+子节点][上移][下移][删除] │
├───────────────────────────────┤
│ 下级位置卡（subNodes 列表）      │
├───────────────────────────────┤
│ 此位置的物品卡：物品数            │
│   [+添加物品] + items 列表        │
└───────────────────────────────┘
```

## 功能模块说明
- 节点信息：显示 name 与 pathText（完整路径区分同名节点，TBD-004）；重命名/上移下移（排序只影响展示，TBD-006）。
- 下级位置：subNodes 列表，点击进入子节点（层级树）。
- 此位置物品：显示该节点下物品，状态文本映射 at_home/unknown/out/borrowed；添加物品默认带入当前 nodeId（item-edit?nodeId=）。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | "此位置暂无物品" / 无下级卡 | `items.length===0` / `subNodes.length===0` |
| 加载中 | 无（本地同步读取） | —（实现缺口） |
| 成功 | 节点信息 + 下级 + 物品列表 | 有数据 |
| 错误 | 无独立错误态 | —（实现缺口） |
| 操作中断 | `showModal` 重命名/新增下级（editable）+ HAS_LINKS 关联保护 | 点对应操作 |

## 交互说明
- 按钮无 disabled；删除含物品的家具/节点时阻断并提示先迁移或归档（MVP-015）。
- 跳转：navigateTo→node?id=（子节点）/item-detail?id=/item-edit?nodeId=。
