# 示意图：物品添加/编辑（UI-011 · pages/item-edit/item-edit）

> 依据：`pages/item-edit/item-edit.wxml` + `.js`。渐进式建档与连续添加（MVP-017/018/022）。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ 标题卡（添加/编辑/连续添加）      │
├───────────────────────────────┤
│ [formError 错误提示]            │
│ 表单：名称* / 分类 / 跟踪模式      │
│   [库存字段：数量/单位/阈值]       │
│   [当前位置 / 位置状态]           │
│   备注                          │
│   [保存] [保存并继续(非编辑)]     │
└───────────────────────────────┘
```

## 功能模块说明
- 必填仅名称；分类/照片/备注/位置可选，支持渐进完善（MVP-022）。
- 跟踪模式：location/inventory/hybrid；`needInventory`（inventory/hybrid）时显库存字段（MVP-026）。
- 连续添加：非 editing 时显示"保存并继续"，保存后清空表单原地停留（MVP-018）。
- 位置：`!hasNode` 时显示位置状态字段（unknown/out/borrowed），从收纳节点进入时默认带入 nodeId。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 空白表单（新建） | `!editing` |
| 加载中 | 无（本地同步读取） | —（实现缺口） |
| 成功 | toast + `navigateBack`（非连续）/ 原地停留（连续） | validate 通过 |
| 错误 | 表单顶部 formError | 名称为空 / 数量<0（validate） |
| 操作中断 | 无（无确认弹窗，校验为即时拦截） | — |

## 交互说明
- picker：onCat/onMode/onUnit/onNode/onLoc；按钮无 disabled。
- 校验：名称必填、数量≥0；无页面跳转，保存后返回或原地。
