# 示意图：库存总览（UI-015 · pages/inventory/inventory）

> 依据：`pages/inventory/inventory.wxml` + `.js`。易耗品清单与低库存入口（MVP-026~030）。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ 标题卡：易耗品库存 + lowCount 标签 │
├───────────────────────────────┤
│ 库存卡列表（wx:for list）         │
│   名称 + 余额/单位 + low 标记      │
├───────────────────────────────┤
│ 空状态块                         │
├───────────────────────────────┤
│ [查看提醒中心（lowCount>0）]      │
│ 右下 FAB「+」                    │
└───────────────────────────────┘
```

## 功能模块说明
- 库存卡：显示余额与单位（`item.low` 样式三元标红低库存）；点击进入详情（openDetail）。
- 提醒入口：`lowCount>0` 时显示"查看提醒中心"（goAlerts）。
- FAB：进入 item-edit 新增库存物品。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | "还没有库存物品" | `list.length===0` |
| 加载中 | 无 | —（实现缺口） |
| 成功 | 库存卡列表 + 条件提醒入口 | 有数据 |
| 错误 | 无独立错误态 | — |
| 操作中断 | 无 | — |

## 交互说明
- 本页为 tabBar 页；跳转 navigateTo→inventory-detail?id=/alerts/item-edit。
- 按钮无 disabled。
