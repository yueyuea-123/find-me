# 示意图：物品详情（UI-012 · pages/item-detail/item-detail）

> 依据：`pages/item-detail/item-detail.wxml` + `.js`。渐进档案、库存与历史入口（MVP-019~025）。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ [整页 wx:if="{{item}}"]        │
│ 概览卡：名称 + 管理状态 + 完善度条 │
├───────────────────────────────┤
│ 当前状态卡：位置/照片/备注        │
├───────────────────────────────┤
│ 库存卡（inventory/hybrid 时）     │
│   余额 + 低库存/正常 tag           │
├───────────────────────────────┤
│ 操作卡：编辑/移动/历史/库存/       │
│   结束管理 ↔ 恢复（互斥）          │
└───────────────────────────────┘
```

## 功能模块说明
- 概览：完善度进度条体现渐进式建档（MVP-022）；管理状态 active/ended。
- 当前状态卡：位置（confirmed/unknown/away/borrowed）、照片（wx.previewImage）、备注。
- 库存卡：`trackingMode!=='location' && inv` 时显示；阈值>0 时显示低库存/正常 tag。
- 操作卡：mgmt active→"结束管理"、ended→"恢复"，互斥显示。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 整页空白（无 item 组件） | `!item`（实现缺口：无空态提示） |
| 加载中 | 无 | —（实现缺口） |
| 成功 | 概览+状态+库存(条件)+操作卡 | item 存在 |
| 错误 | 无独立错误态 | — |
| 操作中断 | `showModal` 结束管理（含 NEED_DISPOSAL 库存处置 editable）/ 恢复 | 点对应操作 |

## 交互说明
- 跳转：navigateTo→item-edit?id=/move?id=/history?id=/inventory-detail?id=。
- 按钮靠 wx:if 条件渲染，无 disabled。
