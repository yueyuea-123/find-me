# 示意图：库存详情（UI-016 · pages/inventory-detail/inventory-detail）

> 依据：`pages/inventory-detail/inventory-detail.wxml` + `.js`。库存交易与阈值（MVP-027~030）。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ 余额卡：名称 + 余额/单位 + tag     │
├───────────────────────────────┤
│ 库存变更卡：类型 chip + 数量       │
│   + 备注 + [提交]                │
├───────────────────────────────┤
│ 阈值设置卡：阈值 + 单位 + [保存]   │
├───────────────────────────────┤
│ 交易记录卡（wx:for txs）          │
└───────────────────────────────┘
```

## 功能模块说明
- 库存变更：类型 chip 单选（入库/消耗/调整），数量>0 校验（`BELOW_ZERO` 拦截），提交写交易并更新余额（MVP-028/029）。
- 阈值设置：阈值 + 单位 picker，保存后影响低库存提醒（MVP-030、TBD-007 预设单位）。
- 交易记录：显示历史交易，空时提示"暂无交易记录"；每次变化留痕、调整与消耗分开。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | "暂无交易记录" | `txs.length===0` |
| 加载中 | 无 | —（实现缺口） |
| 成功 | toast + 原地 `onShow()` 刷新 | 提交/保存通过 |
| 错误 | toast「库存不足 BELOW_ZERO」 | 消耗超过余额 |
| 操作中断 | 无确认弹窗（提交即时） | — |

## 交互说明
- 按钮无 disabled；chip/阈值 tag 用 class 三元切状态。
- `onShow` 校验无库存则 toast 返回；无页面跳转。
