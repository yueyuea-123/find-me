# 示意图：家具编辑（UI-007 · pages/furniture-edit/furniture-edit）

> 依据：`pages/furniture-edit/furniture-edit.wxml` + `.js`。来源标记 manual（MVP-008/009/011）。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ 标题说明卡（添加/编辑）         │
├───────────────────────────────┤
│ [formError 错误提示]           │
│ 表单：类别/名称/外观模型          │
│   尺寸 宽/高/深 · 初始位置 X/Z    │
│   [保存] [删除(仅编辑)]          │
├───────────────────────────────┤
│ 摆放辅助说明卡                  │
└───────────────────────────────┘
```

## 功能模块说明
- 表单：picker 选择类别/模型（模型随类别联动），宽高深与 X/Z 用滚动选择输入；保存校验 roomId 与名称（默认类别名）。
- 删除：仅 editing 时出现，`showModal` 二次确认；含 `HAS_LINKS` 关联保护（有物品时不可直接删，MVP-015）。
- 摆放辅助：贴地/墙面吸附的说明（首版以手动尺寸与拖动为准，MVP-010 降级口径）。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 表单默认值（新建） | `!editing` |
| 加载中 | 无（本地同步读取） | —（实现缺口） |
| 成功 | toast 后 `navigateBack`（500ms） | 保存通过 |
| 错误 | 表单顶部错误提示 | `formError` 非空（缺 roomId/名称等） |
| 操作中断 | `showModal` 删除确认 / HAS_LINKS 关联保护弹窗 | 点删除 |

## 交互说明
- 按钮无 disabled，靠 `wx:if="{{editing}}"` 控制删除按钮显隐。
- 无页面跳转；保存/删除成功后返回上一页。
