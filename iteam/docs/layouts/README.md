## 五态模型说明

SDD 要求覆盖：空数据 / 加载中 / 成功 / 错误 / 操作中断。
实际代码普遍用 `wx:if` + class 三元实现状态切换，**未显式列出全部五态**，尤其"加载中""错误"两态：本地同步读取无加载块，错误由 `app.js` 全局钩子与 `_safeGL` 降级兜底。本目录如实记录已实现状态并标注缺口，不虚构页面元素。若要严格满足五态，属于阶段 H 的实现增强项，需走变更流程（proposal §10 之外）。
