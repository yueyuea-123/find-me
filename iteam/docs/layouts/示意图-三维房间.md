## 功能模块说明（V1.2）
- **空白房间**：进入时按 `rooms.layout`（墙面/地面/默认视角）渲染；无模型也正常显示（F-01）。
- **典型场景模板（V1.2 待实现）**：创建房间时可选空白或典型场景（卧室/客厅/卫生间）；选模板后按房间宽/深/高钳制并预置一组家具（`rooms.source=template`、`templateKey`）；预置家具落库后即普通可编辑对象，与手动添加一致；模板缺失/加载失败降级空白房间并提示（F-07）。
- **模型编辑**：从模型库添加（缺模型用占位）；编辑模式下拖动移动、旋转、缩放模型，实时更新 `position/rotation/size`；越界钳制并提示（F-02、空间边界）。
- **绑定**：选中模型 → 绑定物品档案与收纳节点；复用 `nodes.furnitureId` + `items.currentNodeId`；单物件单位置，换模型保留关联（F-03、绑定边界）。
- **查看**：点选模型查看关联物品清单，跳转 item-detail（F-04）。
- **降级**：`glError`/模型加载失败 → 自动/手动切列表，仍能增删改家具与绑定（F-06）。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 起点选择（空白房间 / 典型场景模板）；选空白后显示"从模型库添加第一个模型"引导 | 新房间 `furniture.length===0` |
| 加载中 | 画布初始化提示（V1.2 待实现） | 进入页面渲染期 |
| 成功 | 空白/已布景三维房间 + 选中模型卡 + 编辑操作 | `glError` 为假 |
| 错误 | 降级提示 + 自动/手动切列表 | `glError`（WebGL/模型加载失败） |
| 操作中断 | `showModal` 确认绑定 / 删除含绑定模型的解绑提示 | 点 confirmBind / 删除绑定模型 |

## 交互说明
- 模式/视图/绑定按钮靠 `wx:if`/class 切 on 态；编辑手势（拖动/旋转/缩放）为 V1.2 待实现。
- 跳转：navigateTo→furniture-edit?id=（编辑）/furniture-edit?roomId=（新增模型）/furniture-detail?id=（收纳）/item-detail?id=（关联物品）。
