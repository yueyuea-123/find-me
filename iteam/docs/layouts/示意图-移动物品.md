# 示意图：移动物品（UI-013 · pages/move/move）

> 依据：`pages/move/move.wxml` + `.js`。移动确认与位置/历史同事务（MVP-023/024、TBD-001/002）。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ 当前信息卡：物品名 + 当前位置/状态 │
├───────────────────────────────┤
│ ① 选择位置状态（chip-grid）       │
│   [在家][未知][外出][借出]         │
├───────────────────────────────┤
│ [外出/借出提示(条件)]             │
│ [② 选择目标位置 picker(在家时)]   │
├───────────────────────────────┤
│ 备注 + [确认移动]                │
└───────────────────────────────┘
```

## 功能模块说明
- 状态 chip 单选：at_home/unknown/out/borrowed（MVP-021、TBD-002 低操作负担）。
- 目标位置：仅 `statusKey==='at_home'` 时显示 picker 选择具体节点。
- 确认移动：`showModal` 提示事务一致（当前位置与历史同写）；"在家但目标为空"用 toast 拦截。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | 当前信息 + 未选状态 | 初始进入 |
| 加载中 | 无 | —（实现缺口） |
| 成功 | toast + `navigateBack`（600ms） | 确认通过 |
| 错误 | toast 提示"在家需选目标位置" | statusKey=at_home 且目标为空 |
| 操作中断 | `showModal`「确认移动」 | 点 confirm |

## 交互说明
- 按钮无 disabled；chip 用 class 三元切 on 态。
- 无页面跳转，成功后返回；首次位置确认语义由 store 层区分，不在本页体现（见 design §7）。
