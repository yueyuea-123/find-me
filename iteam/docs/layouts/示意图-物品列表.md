# 示意图：物品列表（UI-010 · pages/item-list/item-list）

> 依据：`pages/item-list/item-list.wxml` + `.js`。搜索与组合筛选（MVP-019、TBD-008）。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ 搜索卡：关键词输入                │
│   状态/分类/位置 3 个筛选 picker   │
│   [含已结束] 开关                 │
├───────────────────────────────┤
│ 物品卡列表（wx:for items）        │
├───────────────────────────────┤
│ 空状态块                         │
├───────────────────────────────┤
│ 右下 FAB「+」                    │
└───────────────────────────────┘
```

## 功能模块说明
- 搜索：关键词实时过滤；三个 picker 对应状态/分类/位置筛选，支持组合（TBD-008）。
- 含已结束：`includeEnded` 开关，开启后列表含已结束管理物品。
- 物品卡：点击进入详情（openItem）；FAB 进入添加（addItem）。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | "没有匹配的物品"（有筛选）/ "还没有物品档案"（无筛选） | `!loading && items.length===0`，文案由 `hasFilter` 切 |
| 加载中 | `loading` 变量存在但不置 true，无独立加载块 | —（实现缺口） |
| 成功 | 物品卡列表 | 有数据 |
| 错误 | 无独立错误态 | —（实现缺口） |
| 操作中断 | 无（无确认弹窗） | — |

## 交互说明
- 本页为 tabBar 页，被别处 switchTab 进入；跳转 navigateTo→item-detail?id=/item-edit。
- 无 disabled 按钮；筛选状态用 class 三元切换。
