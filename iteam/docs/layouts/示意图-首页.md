# 示意图：首页（UI-001 · pages/index/index）

> 依据：`miniprogram/pages/index/index.wxml` + `.js` 实际结构。仅描述布局与状态，不含代码。

## 页面结构（ASCII）
```
┌───────────────────────────────┐
│ Hero：当前空间名 + 切换         │
│   统计：房间/物品/库存/提醒      │
├───────────────────────────────┤
│ 库存提醒卡（lowCount>0 时显示） │
├───────────────────────────────┤
│ 快捷操作：加物品/加房间/搜索等   │
├───────────────────────────────┤
│ 最近变动列表（历史+交易倒序5条）│
├───────────────────────────────┤
│ 底部说明 foot-note             │
└───────────────────────────────┘
```

## 功能模块说明
- Hero：`stats` 四项统计（房间/物品/库存/提醒），提醒数>0 时徽标加 warn 样式；点击空间名切换（goSpaces）。
- 库存提醒卡：`alerts.length>0` 时显示，进入提醒中心（goAlerts）。
- 快捷操作：goRooms/goItems/goInventory 等入口（switchTab/navigateTo）。
- 最近变动：合并位置历史与库存交易，倒序取前 5；点击进详情（goItemDetail）。

## 页面状态
| 状态 | 展示内容 | 触发条件 |
|---|---|---|
| 空数据 | "还没有变动记录" | `recent.length===0` |
| 加载中 | 代码无独立加载块（onShow 同步刷新） | —（实现缺口，见下） |
| 成功 | 统计 + 提醒卡 + 最近列表 | 有数据 |
| 错误 | 无独立错误态（全局错误钩子兜底） | —（实现缺口，见下） |
| 操作中断 | 无（纯展示页） | — |

## 交互说明
- 提醒卡、快捷入口、最近条目均可点击（bindtap），无 disabled 按钮。
- 跳转：navigateTo→space/alerts/item-edit/item-detail/room(create=1)；switchTab→room/item-list/inventory。

> **与 SDD 五态模型的差距**：加载中/错误两态未显式实现（数据为本地同步读取，错误由全局钩子兜底）。记录于此，不虚构页面元素。
