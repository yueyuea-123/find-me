④ 约束（本原型已实现）

位置估算：照片无真实尺度 → 尺寸参照定标；单视角深度不确定 → 输出带误差半径；遮挡/出画不可恢复。

模型匹配：仅匹配模型库已有类别；库外类别降级占位模型；外观为粗粒度档位；置信度低于阈值强制人工确认。

摆放误差：候选不覆盖已确认；重叠/越界仅提示不自动改；误差经用户确认后消除；降级不影响核心数据。

规格说明 · 三维房间重建

对应产品文档原则：事实与预测分离 · 用户确认优先 · 失败可降级 · 三维与逻辑解耦

一、输入数据

字段类型说明
photos[]图片 ≥1房间多角度照片；建议不同视角有重叠；本原型仅做预览与计数，识别由适配器产出
room.width / depth / height数值（米）尺寸参照，可选；提供即「已定标」，否则「相对估算」
room.calibrated布尔是否带真实尺度；决定位置估算是否按米定标
cameraHint枚举正面朝向参考（本原型默认 +Z 为拍摄侧）

二、处理流程

步骤输入 → 输出约束 / 降级
1 输入校验照片+尺寸参照 → 规范化输入无照片可用内置演示样本；无尺寸参照标记未定标
2 识别照片 → 候选检测集{类别,置信度,外观特征,2D位置,朝向,深度线索,空间关系}三档适配器：auto（端侧读像素，照片不出本机）/ service（自托管视觉服务，照片不出内网）/ 预置样本；结果一律为候选
3 模型匹配候选 → 模型库中类别+外观+尺寸档匹配库外类别→占位模型；低置信→强制确认
4 位置估算2D位置+深度线索+尺寸 → X/Z/朝向 + 误差半径未定标只给相对位置；误差随置信度下降而增大
5 摆放与修正估算位姿 → 三维场景候选对象重叠/越界仅提示；用户拖动/旋转/确认
6 输出确认后对象 → 可查看场景 + 结构化 JSONsource/status 字段区分「AI预测」与「用户确认事实」

三、输出结果（场景 JSON 字段）

字段含义
room房间尺寸与是否定标
objects[].category / model / variant识别类别 / 匹配模型 / 外观档位
objects[].position / rotation / size摆放位姿（米 / 弧度 / 米），Y-up 坐标
objects[].confidence识别置信度（0–1），仅代表预测可信度
objects[].errorRadius位置估算误差半径（米），未定标时更大
objects[].sourcerecognition_candidate 或 user_confirmed
objects[].statuscandidate / confirmed / rejected
alerts[]重叠、越界等摆放告警（仅记录，不自动改）

四、位置估算约束

  • 普通照片无绝对尺度：无尺寸参照时只输出房间内的相对位置，不承诺真实米制精度。
  • 单视角深度不确定：Z 向由画面垂直位置+表观尺寸+深度线索推断，属估算，带误差半径。
  • 遮挡、出画、镜像反射的物体无法可靠恢复，识别环节即标低置信度或直接不输出。
  • 误差半径随置信度下降、未定标而增大；确认前一律以候选圈可视化。
  • 朝向仅作粗粒度（正面/侧向）估计，精细角度由用户在场景中修正。

五、模型匹配约束

  • 只能从已有三维家具模型库匹配；库中无该类别时降级为占位模型，不虚构精确外观。
  • 外观特征为粗粒度档位（颜色/材质/尺寸档），匹配是近似择优，不等于照片真实款式。
  • 置信度低于阈值（本原型 0.6）的匹配必须经用户确认，不得静默计入事实。
  • 用户可手动改选模型/外观，改选后重新以用户确认为准，覆盖预测来源。

六、摆放误差处理约束

  • 候选摆放不得覆盖已确认对象：重新识别只生成新候选，不动已确认事实。
  • 重叠与越界只提示、不自动修改位置，避免算法静默污染用户事实。
  • 用户拖动/旋转/确认后，误差圈消除、状态转为已确认，写入 source=user_confirmed。
  • 识别或摆放失败时保留房间基础数据与已确认对象，可手动添加家具，核心业务不中断。
  • 三维不可用不影响物品列表数据（与 MVP-012 降级原则一致）。

七、接口边界（可替换点）

  • 自动适配（auto，默认）：浏览器用 canvas 读取照片像素，提取主色/墙面色/地面色/明暗分区，按所选房间类型套用家具模板并叠加真实取色与亮区（窗）位置。换任意新照片，颜色与布局随之变化；全部在本机完成，照片不上传。这是启发式估算，不是语义目标识别——类别由模板假定、需用户核对。
  • 真实语义识别（service）：点「服务适配」后，前端把照片以 data URL 通过 POST {服务地址} 发到自托管视觉服务，请求体 {images, room:{w,d,h,type}, photoFeature}；服务返回 {objects:[{id,category,variantHint,conf,u,v,apparent,depthHint,facing,anchor,colorHex?}], meta}，前端规整为同一套候选并进入匹配/摆放。参考服务 recognition-service.py 提供三档后端：mock（零依赖验证链路）、ollama（本地多模态模型，如 qwen2.5vl:7b）、openai（自托管兼容端点）。服务地址可改；照片只发往该地址，须在自有服务器/内网，家庭照片不出内网、未经授权不得用于训练。服务不可用时界面给出错误提示，可切回 auto 继续。
  • 预置样本：bedroom/living 为确定性对照样本，用于无照片或回归验证。
  • 识别结果按照片空间关系（贴墙、置于柜上、窗前、沙发对面）映射为三维位姿；仍是候选、带误差，须用户确认。
  • 真实服务须遵守隐私约束：家庭照片私有处理，未经授权不得传第三方或用于训练。
  • 本原型不预设准确率/耗时/成本等指标，须真机与真实样本验证后确定。
