## 一、打开与视口

- **直接双击 `index.html`** 即可，无 CDN、无后端依赖。
- 顶部舞台切换条：`桌面 1440 / 平板 768 / 手机 375 / 自适应`。响应式相对 `.app` 容器查询，切换即重排。

  - 平板 768：侧栏常驻、卡片 2 列
  - 手机 375：侧栏收进抽屉、卡片 1 列、底部 5 项标签栏、控件升触控档

## 三、交互速查

- 跳转：`data-goto="页面id"`；返回：`data-back`（hash 路由，支持浏览器前进/后退）
- 弹窗：`data-modal-open="#id"`；抽屉：`data-drawer-open="#id"`；关闭：`data-close` / 遮罩 / ESC
- 标签页：`[data-tab-group]` + `data-tab` + `[data-tab-pane].tab-pane.is-active`
- 表单校验：`<form data-validate>` + 控件 `data-required`，错误就近标红并聚焦首错项
- 加载：`data-loading="毫秒"` 按钮、`data-skeleton="#id"` 区块骨架
- 反馈：`data-toast="文案"`（`data-toast-type="error"` 为红），停留 2.2s
- 待确认项：`.anno-red` 红色批注（评审必读，共 11 处）

## 四、配色与组件（低保真铁律）

- 仅灰阶 + 白 + 唯一红 `#d93025`。灰阶：`#111` 标题 / `#3d3d3d` 正文 / `#767676` 辅助 / `#bfbfbf` 禁用。
- 红色仅用于：必填/校验错误、危险/破坏性操作、异常 Alert/Toast、异常标签、待确认批注、热区标注。
- 控件高度 28/32/40（移动 32/40/44）；圆角 2/3/4/全圆；4pt 栅格。
- 组件全部复用 `lofi.css` 既有 class，未改设计系统 token。详见 `lofi-prototype` skill 的 `references/component-spec.md`。
