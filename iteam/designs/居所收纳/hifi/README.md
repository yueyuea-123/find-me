# 居所收纳 · 高保真原型（方案 A 原木日常）

基于已选定的视觉方案 A「原木日常 / Oak & Linen」，覆盖 21 页的**可点击高保真原型**。
双击 `index.html` 即可打开，无需本地服务、无 CDN 依赖。

## 文件
| 文件 | 作用 |
|---|---|
| `index.html` | 21 页高保真原型主体（复用已验证的 DOM 结构与路由） |
| `hifi.css` | 视觉层：上半为交互引擎结构样式，下半为方案 A 高保真皮肤（覆盖 token + 组件质感） |
| `lofi.js` | 交互引擎（路由 / 弹窗 / 抽屉 / 表单校验 / 骨架屏 / Toast / 视口切换） |

## 视觉系统（方案 A）
- **配色**：暖米白画布 `#FAF6EE`、白色大圆角卡、原木棕主色 `#9C6B3F`、苔绿正向 `#6E7F59`、陶红异常/低库存 `#BE5F44`。全部色值来自 `design-tokens.css` 的 `.theme-a`，无新发明色。
- **形态**：卡片圆角 20px、控件 10~14px、柔和暖影 `0 6px 22px rgba(92,68,40,.09)`、无硬边。
- **字体**：无衬线圆润（PingFang / 系统栈），行高 1.65，标题加重字距收紧。
- **语义色**：已定位 / 正常 / 已绑定 / Active / 候选就绪 = 苔绿；位置未知 / 外出 / 借出 / 低库存 / 校验错误 / 危险操作 / 待确认批注 = 陶红。

## 三档视口
顶部舞台条切换「桌面 1440 / 平板 768 / 手机 375 / 自适应」：
- 1440：侧栏常驻、4 列统计、无底部标签栏
- 768：2 列统计
- 375：侧栏收起为抽屉、单列、顶部汉堡、底部 5 项标签栏

## 评审用法
1. 从 **P0 流程总览** 点任意流程节点跳转，走通 5 条主路径（UF-001~005）。
2. 顶部浏览器栏 `←` 返回；支持浏览器前进/后退与 `#/pX` 直接路由。
3. 11 处**陶红批注**为待确认项 Q-01~Q-10，落页可点，评审时逐条拍板。
4. 表单可实测必填校验、Loading、Toast；弹窗/抽屉可开关；含空态 / 骨架 / 无权限 / 关联保护等异常态。

## 版本口径
全文以 **V1.2（CR-001 已批准）** 为基准：三维主路径为手动自由编辑，照片 / 建模任务页（UI-004/005）降为可选分支。页面编号以 21 页真值为准。

## 与线稿原型的关系
`iteam/prototype/index.html` 为灰阶线稿版（Axure 风格），本目录为同结构的高保真视觉版。两者页面、流程、状态、交互完全一致，仅视觉语言不同——便于「先定结构、再定视觉」两阶段评审对照。
