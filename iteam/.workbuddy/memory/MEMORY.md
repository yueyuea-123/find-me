## 项目核心事实
- 产品：三维室内空间与家庭物品管理微信小程序（+ Web 管理后台）；MVP 个人单用户。
- 上位规则优先级：产品总纲 V1.0 > MVP 范围冻结清单 > 业务规则说明书 > PRD > 原型/技术设计。
- 不可突破的原则：事实与预测分离、失败可降级（三维/AI 失败时列表可用）、三维对象与逻辑位置解耦、用户确认优先、数据可追溯。
- 不臆造量化指标：准确率/帧率/耗时/模型数量/照片门槛/AI 成本均须真机验证后确定，不写进合同。
- 隐私：家庭照片私有存储、用户数据隔离、第三方 AI 不得未经授权用于训练。
