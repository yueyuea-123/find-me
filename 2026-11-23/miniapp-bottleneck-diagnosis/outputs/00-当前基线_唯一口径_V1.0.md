## 1. 产品与范围

**产品定位**：家庭物品管理小程序。核心是物品的建档、查找、位置与库存管理；三维房间是物品数据的**呈现层**，不是产品的第二核心。

**交付范围（唯一）**

| 项 | 结论 |
|---|---|
| 数据形态 | **纯本地存储**（`wx.Storage`）。云同步不在交付范围 |
| 移出范围 | 云同步（`cloud-sync`、`dataSync`、13 集合、6 云函数）、云端备份/恢复、云照片存储、管理后台云端统计 |
| 对应需求处置 | PRD-001~004、PRD-030、PRD-032 及 MVP-031/033 的云端部分不纳入本次验收；MVP 冻结清单中的 34 项 P0 以本表为前置裁剪，不再作为整体承诺 |
| 保留能力 | 本地建档、查找、移动历史、库存、提醒、本地备份导出/恢复、照片本地选图与展示 |
| 冲突裁定 | `iteam/README.md`「不上传服务器」与项目档案「13 集合同步」冲突，**以本地为准**；项目档案的云端描述在下一次对账中收敛 |

> 待对账细化（不在本轮裁定）：照片是否落本地文件路径、本地备份是否保留入口，由对账清单逐条标"保留/隐藏/移出验收"。

## 2. 归属模型（已确认）

**归属链：空间 → 家具 → 物品。物品跟随家具，家具跟随空间。**

| 规则 | 口径 |
|---|---|
| 物品归属 | 物品的"在哪个空间/房间"一律由 **物品 → 家具 → 所在房间 → 空间** 推导，物品**不自行维护坐标或房间字段** |
| 家具归属 | 家具归属其所在房间，房间归属空间；家具是物品归属的唯一锚点 |
| 房间的角色 | 房间是空间内的分组与展示单位，**不直接承载物品归属** |
| 收纳节点 | 节点是家具内部的位置细分（抽屉/隔层/收纳盒），属于家具；节点只细化"家具内位置"，不改变归属判断 |
| 物品坐标 | 物品没有三维坐标；三维中的位置只由家具决定 |

### 2.1 两个边界策略（已确认）

| 场景 | 策略 |
|---|---|
| **家具被删除或替换** | 其下物品**不删除、不静默丢失**，统一落回**该空间的「未放置」区**，并保留历史记录；替换外观模型（换 model）不属于删除，物品归属不变 |
| **物品不挂家具（空间直挂）** | **待确认项，尚未决策**。在决策前，实现与文档均不得默认支持、也不得默认禁止；不得写成已决口径 |

> 待确认标记：`OPEN-01 物品是否允许空间直挂`。

## 3. 验收口径（页面与视觉）

| 层 | 口径 |
|---|---|
| 页面总数 | 以 `app.json` 注册为准（当前 21 页）。**不得以"高保真只有 8 页"为由删减页面** |
| 视觉验收 | 交付稿 01–08 共 8 页按高保真 PNG/SVG 验收（结构、间距、层级） |
| 其余 13 页 | 只做**一致性验收**：设计令牌（`design-tokens.json` V1.1）、组件规范、空态/加载/错误态；**不做像素级比对**，**本轮不再重做视觉** |
| 全局换色 | 21 页统一到 V1.1 色板视为"设计令牌统一"，**不等同于** 21 页都做了高保真结构对齐 |
| 功能验收 | 21 页按《逐页交互说明书 V1.2》+ 本文件业务口径验收；云端页面按"本地降级态"验收，不与云端联调 |

**收敛结论**：8 页对设计稿，13 页对规范；两者不互相否定，也不再用"全量对齐"描述本轮工作。

## 4. 三维交互口径（已确认）

| 项 | 结论 |
|---|---|
| 基准 | **《客厅三维空间交互与开发设计规范 V1.3》A 方案** |
| 家具操作 | **禁止直接拖动家具**。选中后用「移动/旋转/尺寸」明确按钮或数值编辑 |
| 相机 | 空白单指拖动转视角、双指缩放；相机变化不算数据变更 |
| 作废口径 | V1.0/V1.1 及 README 中的"拖动摆放、捏合缩放家具、双指扭转、长按删除"**全部作废** |
| 保存语义 | 采用"编辑 → 完成 → 保存/撤销"；**保存前不得落盘**（当前实现为即时落盘，属对账整改项，不在本轮改代码） |
| 边界 | 三维只负责呈现与家具摆放；物品增删改查仍走物品页与物品规则，不在三维页新开业务入口 |

## 6. 明确不做（本期）

1. 不做云同步、云端账号/多端、云端备份与云照片存储。
2. 不做 AI 识别、照片生成三维模型、自动家具识别与自动摆放。
3. 不做"点物品反向定位到三维高亮"（本期）。
4. 不做多人协作、共享空间、角色权限。
5. 不做复杂运营后台、订阅消息、支付/采购。
6. 不做整体重写、换框架（Taro/uni-app）、重做数据模型。
7. 不做三维自由拖拽家具（与 V1.3 冲突）。
8. 不做物品独立坐标、独立房间字段。
9. 不做无设计依据的页面视觉重构。
10. 不为通过门禁修改测试断言；门禁分数不代表真机验收通过。
