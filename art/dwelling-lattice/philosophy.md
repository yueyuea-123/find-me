# 居所晶格 · Dwelling Lattice

**一场关于“安放”的生成艺术运动**

居所不是被画出来的，而是被安放出来的。每一件家具在落定之前，都经历过一次微小的偏移与回正；每一个房间都不是孤立的构图，而是从同一块地面上递归分割出的领地。居所晶格把“家”理解为一张持续被量化的平面：5 厘米是它的最小语法单位，墙面是它的引力，房间与房间之间的缝隙是它留出的呼吸。美不来自最终的静止画面，而来自物件从混沌漂移到格点、从悬置落向地面的那一小段过程。

算法以递归二分生长户型。一块矩形地面被反复切分，直到房间数量与面积层级达到平衡；每次切割的位置由种子决定，却始终服从最小房间尺度与长宽比约束。随后，30° 等距投影把平面折叠成一座剖开的娃娃屋：低矮而克制的墙体让所有房间同时可见，地面上的细密线条则把 5 厘米的晶格悄悄显露出来。观者看到的不是一张效果图，而是一套空间规则在同一瞬间的全貌。

家具的到达是整件作品的核心仪式。每件家具先以一个偏离格点的姿态悬在空中，随后在缓动曲线中下落、平移、回正，最终精确地停在 5 厘米晶格的整数倍上。落点并非随意：它同时受到房间类型、墙面亲和、家具之间的排斥距离与可用面积的约束。拖动过程只改变预览，真正的“落盘”发生在动画结束的一帧——这与真实居所中被反复推敲的摆放经验同构。每一次落定都留下一圈极淡的定位刻线，像施工图上尚未擦去的铅笔标记。

物品不拥有坐标。它们以微小光点的形态从房间上方被家具吸引，沿弧线沉降，最后只凝结为一个数字：家具顶部安静出现的“N”。数量为零时，角标不出现；有物品时，它也不喧哗，只提示“这里有东西”。少数物品永远不被任何家具接纳，它们以空心圆环的姿态在平面上方缓慢漂移——这是对“删除家具不应删除物品”的温柔提醒，也是对“未放置”这一状态的诗性保留。

种子决定一切，又从不重复。同一枚种子永远生成同一座住宅、同一套家具位置、同一批物品落点；相邻的种子却可能给出完全不同的户型。噪声只负责毫米级的微差：地面的色温、家具木色的深浅、植物叶簇的疏密。结构由规则裁定，气质由种子赋予。每一幅画面都是一次性的居住提案，而不是可无限复制的壁纸。

这件作品必须像一件被反复打磨的器物。每一处投影角度、每一条网格线的不透明度、每一次缓动的时长、每一枚角标的字重，都经过成百上千次目视调校；家具的遮挡顺序、墙体的高度阈值、物品降落的弧线高度，全部服务于“一眼读懂整座居所”的克制。它应当看起来像一位长期研究空间与量化美学的作者，在无数次失败后留下的、举重若轻的成品——meticulous, painstaking, master-level.

## 算法语汇（供实现者参考）

- **户型**：矩形平面上递归二分（BSP），最小房间尺度约束，房型按面积排序后分配（客厅 / 卧室 / 厨房 / 卫生间 / 书房 / 阳台 / 储物）。
- **投影**：30° 等距投影，Y-up；低墙剖切，地面微网格显示吸附晶格。
- **安放**：墙面亲和放置 + AABB 排斥 + 全局 5cm 网格吸附；落点由种子与房间类型共同决定。
- **仪式**：墙升起 → 家具从偏格位置缓动落定并留下定位刻线 → 物品沿弧线沉降 → 角标浮现。
- **物品**：按家具体量加权分配，绘制为顶面微光；约 6% 为“未放置”空心环，永久缓慢漂移。
- **复现**：`randomSeed / noiseSeed` 固定；同一 seed 永远得到同一座住宅与同一批落点。
