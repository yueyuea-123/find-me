# Dwelling Lattice · 居所晶格

一件根据《居所收纳》小程序三维空间需求与交互口径生成的**交互式生成艺术作品**。它不是产品截图，也不是新的功能页面，而是把当前空间模块的规则翻译成一套可被种子复现的视觉语言。

## 查看

直接用浏览器打开 `index.html`（需联网加载 p5.js CDN 与 Google Fonts）。

- **Seed**：上一枚 / 下一枚 / 随机 / 直接输入。同一枚种子永远生成同一座住宅。
- **Parameters**：房间数、家具密度、吸附网格、物品数、墙高。
- **Colors**：地面、墙体、强调色。
- **Download PNG**：导出 1200 × 1200 的成品图，标题、比例尺与参数说明都在画布内。

## 与现有文档的对应

| 文档口径 | 作品中的算法表达 |
| --- | --- |
| 等距视角（《客厅三维空间交互与开发设计规范 V1.4》§3.1 默认视角与视角预设） | 30° 等距投影；作品采用固定视角，以保证版画式成品的可复现与一眼可读（非产品规则） |
| 5cm 网格吸附（V1.4 §5.1） | 家具落点全局吸附到 `snapGrid` 的整数倍，默认 5cm |
| 拖动只改预览，抬手一次性落盘（V1.4 §3.2） | 家具先以偏格姿态悬置，缓动落定后才成为最终位置，并留下定位刻线 |
| 家具是物品入口，物品不绑定三维坐标（V1.4 §5.4；交互规范 §4.1） | 物品以微光粒子汇入家具，最终只凝结为“内有 N 件”角标，不画成独立模型 |
| 删除家具不静默删除物品、未放置兜底（业务规则） | 约 6% 的物品以空心圆环永久漂移，始终不被任何家具接纳 |
| 七类房型模板与默认家具（《02空间功能设计》§三） | 七类房间目录 + 对应家具原型，按房间类型与墙面亲和度生成布局 |
| 房间是模板的独立副本（《02空间功能设计》§三） | 每枚种子生成一套独立户型；相邻种子互不影响 |

## 定位与边界

- 这是**独立的概念视觉作品**，位于 `art/` 下，不进入 `iteam/miniprogram/` 交付包，不改变 MVP 范围与冻结规则。
- 可用于评审演示、加载/空状态视觉参考，或作为空间模块的生成式视觉语言样例。
- 如需接入小程序，需要另行评估包体、性能与渲染方案；小程序端不建议直接运行 p5.js。
